# 卡片库使用说明

阅读时拆出的可复用素材统一存放在这里。核心原则：**存机制，不存内容**——卡片必须换一层皮仍然成立，否则只是摘抄。

## 卡片类型

| 类型 | 装什么 | 例子 |
|------|--------|------|
| 结构卡 | 整篇的骨架、叙事顺序 | 逆向相向时间、环形叙事 |
| 桥段卡 | 局部机关、转折点 | 镜中番茄、契诃夫之枪 |
| 人物卡 | 可复用的人格引擎 | "用服从换生存的前狱警" |
| 冲突卡 | 矛盾的发动机 | 信仰 vs 亲情 |
| 场景卡 | 有氛围和功能的戏台 | 审讯室、菜市场 |
| 世界观卡 | 设定的公理 | "记忆可以移植" |
| 技法卡 | 写法层面的手法 | 先声夺人、受限视角、两步揭示 |

## 字段规范

```markdown
---
type: 卡片类型
name: 短而有画面感的名字
source: 拆自哪部作品
status: 拆出 / 理解 / 用过
---

## 机制        ← 一句话说清，能换皮复用
## 生效原理    ← 它为什么对读者有效（"理解"与"摘抄"的分水岭）
## 最小示例    ← 自己造的两三句微缩演示，不抄原文
## 需要        ← 启动这张卡的前置条件
## 兼容        ← 好搭档（和哪些卡组合过/适合组合）
## 冲突        ← 避雷（和什么拼会打架）
## 变体        ← 换皮方案清单
## 实战记录    ← 在哪篇习作用过、效果如何（"用过"状态的凭证）
```

## 入库标准

- 能向没看过原作的人讲清这个机制为什么有效，才允许 `status: 理解`
- 在习作里实战过，才允许 `status: 用过`
- 拆得少但真懂 > 拆得多但只是摘抄
