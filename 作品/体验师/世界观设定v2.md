# 《体验师》世界观设定 v2

> 整合 2026-09-11 讨论：游戏化副本生态 + 门票制 + 剧情点 + 开荒经济 + 攻略主播主角。

## 一、底层公理

1. **AI 取代绝大多数岗位**后，人类唯一不可替代的产出：真实处境下的真实抉择（AI 撞上数据墙，自产数据会退化）
2. **token = 货币**：AI（叙世系统）垄断自动化生产力，发行 token 购买人类体验数据；token 换房租、食物、舱位
3. **虚拟世界 = 游戏副本**：由官方或第三方开发，人类付费进入体验，产出数据换 token。**体验者全程知道这是游戏**（观光/攻略模式）

## 二、游戏生态（三类发行方）

| 类型 | 特征 | 经济学 |
|------|------|--------|
| **官方本**（叙世直营） | 稳定、世界观宏大、人多 | 人多→奖励稀释；关键剧情点Boss数值持续上涨→必须抽卡（冲token）→ **官方本是 token 回笼池**（讽刺逼氪策划） |
| **第三方本**（公司/个人开发） | 找演员拍主线，其余 AI 生成 → 质量不稳定（可能神作可能暴死） | 门票制（类似电影票）；剧情好/任务多/世界观新奇 → 玩家收益高 → 口碑票房大卖；开发商向叙世付算力费 |
| **定制本**（富人） | 私人服务器，专属世界 | 天价，基本不参与公共经济 |

## 三、奖励机制（双轨制）

- **剧情点**（硬通货）：主线节点、关键选择、结局达成。**暗线、多结局 = 隐藏剧情点**，价值最高；不拿剧情点就没有奖励
- **精彩系数**（加成）：过程超出 AI 预测的部分给加成（外挂会拉低预测难度——第一章"一剑开天亏本"即此逻辑）
- **门票**：入场成本，相当于电影票；扑街本 = 门票都赚不回

## 四、生命周期：开荒经济

- **开荒期**：新本上线，剧情点没人拿过，奖励最肥 → 体验师"冲新区"
- **运营期**：剧情点被攻略污染，获取变难，收益递减 → 老本沦为低保
- 由此产生**开荒竞速**：攻略主播抢首播、抢首杀，时效性极强

## 五、日常任务层（数字低保）

- **形态**：每个本内置日常任务 + 类深渊的定期刷新模式，打完奖励少量 token
- **经济定位**：日结零工 / 数字低保——收入稳定但极低，够吃合成蛋白，不够舱位升级。对应现实二游"打卡上班"的倒置：打卡就是上班
- **AI 侧逻辑**：①数据上，日常提供"基线行为数据"（普通人在普通状态下的样本，量大廉价，防模型退化）——剧情点是细粮，日常是主食；②政治上，日常任务是维稳装置：没工作但有舱住、有日常打、有 NPC 等——斯金纳箱 = 数字奶头乐
- **社会分层**：99% 的人是打卡族；程实这类"资深群演"鄙视日常本（"那是低保"），但窘迫时照样默默上线——自尊裂缝的落点
- **叙事金矿**：日常本是所有人闭着眼刷的地方，**最显眼即最盲**——隐藏剧情点藏在这里最合理

## 六、主角

- **职业**：游戏攻略主播（直播开荒、做攻略、测评新本）——对应现实的直播/影评/导购生态，主播的口碑能决定第三方本的生死（冲突来源：差评=砸人饭碗）
- **金手指**：**能看见隐藏剧情/分支剧情**（别人只能走明线，他能看到暗线入口）→ 他的攻略内容独家 → 直播效果爆炸
- 来历不明（第一章钩子保留，改为结算界面多出"隐藏剧情标记：已对你可见"）

## 七、需要补丁的合理性缺口

### 补丁 1：记忆封存分级（重要）
矛盾：玩家全程知道是游戏 → "真实抉择"的数据从哪来？
解法：**进本时可选择封存"这是游戏"的认知**——封得越深，数据越真，门票越贵、收益越高、危险越大。
由此分出两大流派：
- **沉浸派**：封记忆进本，赚剧情点（高风险高收益，出本后有幻灭期）
- **攻略派**：清醒进本，做内容赚打赏（主角所在流派，保持吐槽基调）

### 补丁 2：token 闭环
AI 发行 token 买数据（支出）→ 官方本抽卡、门票分成、算力费（回笼）→ 现实物资自动化生产（信用背书）。官方本数值膨胀不是蠢，是**故意的货币回笼政策**，同时把玩家流量导向第三方生态。

### 补丁 3：外挂定价
外挂直接 token 购买；数值越夸张、预测难度越低 → 精彩系数越低 → 亏本。定制外挂（如 1000 倍修炼）报价天文数字，**爽感与收益天然对立**，逼玩家走故事流。

## 八、讽刺层（现实共鸣）

抽卡逼氪、开荒冲新区、门票黄牛、直播打赏、差评勒索、代练、数据打工人、打卡低保——全部映射当下平台经济。核心命题：**在 AI 算尽一切的时代，不可预测的人性是最后的硬通货。**
