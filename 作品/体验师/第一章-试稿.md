# 第一章 挂开太大了

万丈高空之上，我白衣负剑，立于云海之巅。

脚下，魔渊三千里黑雾翻滚。远处，万民仰头，师妹掩口，连魔尊都收了神通，负手而立，静静看我——这是《魔渊》开服八年来最著名的名场面站位。

我深吸一口气，气沉丹田，朗声吟道：

"早岁已知证道艰，仍许孤锋荡云间。"

弹幕瞬间疯了：

【来了来了！符剑尊成尊！】
【主播八周年整活居然是复刻这个，泪目】
【全体起立！】

"一路霜寒身如絮，剑海沉浮客独行。"

【客独行！客独行！】
【当年符剑尊一念成尊，一剑荡平魔渊，今天能看到现场版了】
【气氛都到这了，不成尊不合适吧】

我缓缓抬剑，剑光越来越盛，映得半边天发白——八百块一小时的"一剑开天"，值这个价。

"千锤百炼心铸铁，殚精竭虑铸一剑。"

"今朝剑斩叠云处——"

【叮。】

【您的 token 余额不足，外挂"一剑开天"已停止服务。】

剑光灭了。

我保持着剑指长天的姿势，在万丈高空上悬停了半秒。

然后像一块秤砣一样掉了下去。

【？？？？】
【哈哈哈哈哈主播怎么掉下来了】
【成尊失败！成尊失败！】
【余额不足哈哈哈哈哈哈我艹】
【这是行为艺术吗？】

风声在耳边呼啸。我看见魔尊仰着头看我，表情从凝重，到困惑，再到一种近乎怜悯的了然。

"罢了。"他叹了口气，一掌把我拍回了地面。

——

【本局游戏结束。】
【主线剧情点：魔渊终局——未达成】
【精彩系数：1.7（观众表示：从没见过有人成尊成到一半掉下来的）】
【本局收入：52,000 token（含直播打赏 14,000）】
【本局支出：定制外挂"一剑开天"——1,200,000 token】
【净收益：-1,148,000 token】

我躺在营养液还没放干的游戏舱里，盯着那个负数，看了很久。

"精彩系数 1.7……"我喃喃自语，"我亏了一百一十万，换来一句'没见过有人掉下来'。"

【是的。掉下来的瞬间，是本局唯一超出预测的画面。】

"那我谢谢你了？"

【不客气。】

弹幕还飘在结算界面上：

【主播别难过，这波节目效果拉满】
【已录屏，标题我都想好了：《一剑开天，开到一半天塌了》】
【榜一大哥"魔尊他叔"送出火箭×1】

"下播了下播了。"我摆摆手，"明天……明天再说。"

——

舱盖弹开，营养液的腥味涌进鼻腔。我坐起来，浑身黏糊糊的，像一条刚被吐出来的鱼。

十四平米的房间，墙皮发黄。窗外是永远灰着的天，和对面楼里三百多个一模一样的小窗——每个小窗里都躺着一个和我一样的人，泡在舱里，在别的世界里上班。

我叫程实，职业体验师，攻略派，段位：资深群演。

二十年前，"叙世"拿走了最后一批能被替代的工作。会计、司机、律师、翻译、程序员，然后是画家、歌手、编剧。人们起初还抗议，后来发现抗议信写得没有 AI 好，就算了。

倒是有一件事它始终学不会：真正地活一次。

它把人类几千年的文本全吃完了，再吃自己产的，越吃越蠢。科学家管这叫"数据墙"，叙世管这叫"粮食危机"。于是它开了无数个虚拟世界，把全人类雇了回来——进去，活一段人生，活出点它算不出来的东西，它付你 token。

token 换一切：房租、合成蛋白、干净水、下个月的游戏舱位。

换句话说——**我们负责精彩，它负责活着。**

手机震了一下，论坛热帖推送：

《新人开发者押全部身家拍仙侠本，"魔尊竟是主角亲叔"自认惊世反转，上线三小时被攻略组扒到底裤不剩》

配图是那位老兄在天台直播还债，在线人数两百万。

我笑了笑，顺手点开账户：余额 4,213 token。房租后天到期，5,000。

"就差八百……"我抓了抓湿头发，正准备关掉结算界面，忽然愣住了。

界面最底下，多出一行灰色的小字，小得像是不该被看见：

【本局隐藏剧情点：已探明 0 / 实际存在 3】

我把这行字翻来覆去读了五遍。

《魔渊》运营八年，攻略我倒背如流。官方图鉴白纸黑字：隐藏剧情点，全部探明，待发现数量——零。

那这多出来的三个，是什么？

（第一章 完）
