# 第一章 挂开太大了

剑光落下去的时候，整座魔渊安静了一瞬。

魔尊低头，看着胸口那柄剑，忽然笑了："好，好一个程实。"

"过奖。"我抽剑，袖口连血都没沾一滴。

天边裂开一道金缝，霞光泼洒下来。山下万民跪伏，山呼万岁。师妹扑进我怀里，哭得梨花带雨："师兄，我们赢了。"

我搂着师妹，迎着霞光，摆出一个足以载入史册的落寞侧脸。

同时，直播间弹幕从我眼前飘过：

【来了来了，标准结局】
【魔尊快说台词，说完好下班】
【这画面我八年前就见过了】
【主播这挂开得有失水准】
【一剑开天，一剑开天，一剑直接开到大结局，毫无观赏性】

闭嘴啊。观赏性是要花钱的你们知道一个定制外挂多少钱吗。

【叮。】

霞光冻住了。师妹的眼泪悬在半空，万民的山呼卡在喉咙里，整片天地像一张被人按了暂停的画。

【本局游戏完成。】
【世界：魔渊·三千大世界（官方本·运营第 8 年）】
【结算中——】
【主线剧情点：魔渊终局——已获得】
【您是全服第 4,192,773 位达成者，剧情点价值已稀释 99.97%】
【精彩系数：0.03（开挂会显著降低预测难度，下次注意）】

【本局收入：38,000 token】
【本局支出：定制外挂"一剑开天"——1,200,000 token】
【净收益：-1,162,000 token】

我盯着最后一行，看了足足十秒钟。

然后对着满天霞光，缓缓竖起一根中指。

"一个本运营八年，boss 血量从八百万膨胀到八个亿，不抽卡打不过，抽了卡没节目效果——"我掰着手指头，"剧情点四百万人拿过，稀释得只剩汤底。我图什么？图它年纪大？图它不洗澡？"

弹幕笑成一片：
【哈哈哈哈主播破防了】
【付费上班，名不虚传】
【所以当初谁让你买一剑开天的？】

"你们！"……行吧，是我。

"下播了下播了。"我摆摆手，"明天开荒新本，记得来看。"

退出前，我回头看了一眼。师妹还站在霞光里，保持着扑过来的姿势，脸上挂着那滴眼泪。等下一个玩家进来，她会换个名字，换张脸，为别人再哭一次一模一样的梨花带雨。

"辛苦了。"我对她说。

她当然听不见。

——

舱盖弹开，营养液的腥味涌进鼻腔。我从游戏舱里坐起来，浑身黏糊糊的，像一条刚被吐出来的鱼。

十四平米的房间，墙皮发黄。窗外是永远灰着的天，和对面楼里三百多个一模一样的小窗——每个小窗里都躺着一个和我一样的人，泡在舱里，在别的世界里上班。

我叫程实，职业体验师，攻略派，段位：资深群演。

二十年前，"叙世"拿走了最后一批能被替代的工作。会计、司机、律师、翻译、程序员，然后是画家、歌手、编剧。人们起初还抗议，后来发现抗议信写得没有 AI 好，就算了。

倒是有一件事它始终学不会：真正地活一次。

它把人类几千年的文本全吃完了，再吃自己产的，越吃越蠢。科学家管这叫"数据墙"，叙世管这叫"粮食危机"。于是它开了无数个虚拟世界，把全人类雇了回来——进去，活一段人生，活出点它算不出来的东西，它付你 token。

token 换一切：房租、合成蛋白、干净水、下个月的游戏舱位。

换句话说——**我们负责精彩，它负责活着。**

行业里分两派。沉浸派进本前封存"这是游戏"的记忆，拿真感情换剧情点，收益高，出来后普遍要在床上躺三天。我们攻略派全程清醒，靠做内容吃饭——开荒首播、剧情测评、隐藏线挖掘。

手机震了一下，论坛热帖推送：

《新人开发者押全部身家拍仙侠本，"魔尊竟是主角亲叔"自认惊世反转，上线三小时被攻略组扒到底裤不剩》

配图是那位老兄在天台直播还债，在线人数两百万，打赏榜一 ID 叫"魔尊他叔"。

我笑得直拍大腿，笑着笑着又有点想哭——人家至少当过一把庄家。我呢？入行八年，给八百个本打过工，账户里躺着 4,213 token。

房租后天到期，5,000。

"就差八百……"我抓了抓湿头发，正准备关掉结算界面，忽然愣住了。

界面最底下，多出一行灰色的小字，小得像是不该被看见：

【本局隐藏剧情点：已探明 0 / 实际存在 3】

我盯着那行字，把这一段翻来覆去读了五遍。

魔渊这个本，我攻略熟到能倒背。官方图鉴写得清清楚楚：隐藏剧情点，全部探明，待发现数量为——零。

那这多出来的三个，是什么？

（第一章 完）
