# 《体验师》第二章大纲 · 八年没人问过他为什么

> 承接第一章钩子：魔渊"已探明 0 / 实际存在 3"的隐藏剧情点。
> 本章任务：自尊裂缝落地（低保本）+ 金手指首次实战 + 第一个隐藏点揭开 + 升维钩子。

## 事件分解

**E01 鬼畜出道（开场·喜剧）**
- 成尊失败的录屏爆了：《一剑开天，开到一半天塌了》冲上热榜，鬼畜区二创刷屏
- 黑红也是红：直播间涨粉，但打赏寥寥——观众是来看笑话的，不是来消费的
- 房租倒计时：还剩两天。他嘴硬"我不打低保"，然后默默排进了魔渊日常队列
- 弹幕：【主播来打工啦】【昨天不是说不打日常吗】【真香】

**E02 打卡上班（世界观展示·丧燃）**
- 魔渊日常区实况：几百个玩家排队领任务，全程无交流，面无表情，肌肉记忆式跑图
- 细节：有人闭着眼都能走完全程；有人一边做日常一边在舱里吃饭
- 程实的内心吐槽：八年前这游戏开服时也排队，那时人人眼睛发亮，现在同一批人，眼睛没了
- 规则落地：日常任务奖励 80 token/环，一天上限十环——数字低保

**E03 金手指亮了（转折）**
- 跑到第三环"给村口的陈伯送十株止血草"时，他的视野边缘浮起一行只有他能看见的灰字：
  【该 NPC 存在未探明隐藏剧情 · 入口：????】
- 他愣在原地。这个任务全服日活千万次，攻略里就一行字："跑腿任务，无彩蛋。"
- 八年了，几百万人从陈伯身边路过，没有一个人停下来说过一句话
- 他试着脱离任务流程，蹲下来跟陈伯闲聊——系统没有对话树选项，陈伯只会重复"少侠，止血草带来了吗"
- 但金手指的灰字还在闪。他换了个思路：不聊任务，聊**他自己**——"陈伯，你这腿是怎么伤的？"
- 陈伯的台词库卡了一下。然后说了一句不在任何攻略里的话

**E04 第一个隐藏点（本章情感核心，留大半给正文发挥）**
- 陈伯的秘密：他是魔渊**开服第一版**的角色。最初的魔渊没有魔尊、没有抽卡，只是个种地的村庄，陈伯是村口的教书先生；第三版大更新"魔渊入侵"，村庄一夜之间被写进战火，他的学生、他种的田、他的身份全被新的剧情覆盖——只有他还留在村口，任务文本从"教书育人"改成了"收止血草"
- 他不知道自己为什么收止血草，就像打卡族不知道自己为什么打卡
- 隐藏剧情点的获取方式不是打，是**听完**
- 直播弹幕从【水时长】刷到【？】刷到集体沉默——在线人数开始疯涨
- 获取动画：【隐藏剧情点"村口先生"已收录。精彩系数：？？？】——系统自己都没给这个打过分

**E05 余波与钩子（收束）**
- 奖励到账：数额远超日常本规格（隐藏点+全网首播加成），房租有了，还能还一部分外挂债
- 但问题来了：陈伯这段剧情**不在官方图鉴里**——不是"没被发现"，是"不在档案里"
- 有人在一个运营八年的官方本里，私自埋了三段没有登记的故事。谁埋的？（厂商？叙世自己？还是……NPC？）
- 章末钩子：程实再去找陈伯时，村口空了。任务还在，NPC 换了人。新 NPC 笑着问："少侠，止血草带来了吗？"
- 陈伯消失了。系统日志里，没有这个人存在过的记录

## 本章功能定位

- 金手指规则落地：隐藏点以"灰字标记"形式只有他可见；获取靠"走心"而非战斗——确立本书"故事流"玩法
- 讽刺升级：陈伯 = 被更新迭代碾过的旧版本内容 = 被时代抛下的人（打卡族的镜像）
- 主线悬念接入：官方图鉴之外的故事 → 直通终极悬念"这些隐藏剧情是谁埋的"
- 直播事业线点火：黑红→内容爆红，下章自然进入"开荒竞速/同行竞争"

## 待正文细化

- 弹幕情绪曲线：嘲讽→困惑→沉默→爆发，这是本章的节奏轨
- 陈伯消失的速度要快到反常——制造"有人在盯着他"的寒意
