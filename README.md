# zero-to-scribe

Exercise repository for fiction. From zero, learning to write.
小说练习仓库，从零开始学习写作。

## 简介

这是一个个人写作练习仓库，用来记录从零开始学习小说创作的过程：练笔片段、短篇习作、读书笔记与写作心得都会沉淀在这里。

## 目录结构

**输入 → 加工 → 产出** 的单向流动：

- **资料**：原始素材——书籍章节、写作题目、课程教案（解忧杂货店、501 个创意写作练习、推理小说课程等）
- **卡片库**：从资料中拆出的可复用素材卡（结构 / 桥段 / 人物 / 冲突 / 场景 / 世界观 / 技法），存机制不存内容，规范见 `卡片库/README.md`
- **模板**：写作流程模板（场景写作流水线、雪花写作法）
- **笔记**：拆片笔记、风格拆解、阅读思考与写作心得
- **练笔**：拆片作业、仿写、原创场景与短篇习作
- **app**：未来的写作辅助软件（占位，规划中）

## 说明

仓库内容会持续更新，所有习作均为练习性质，欢迎交流与指正。
