# zero-to-scribe

Exercise repository for fiction. From zero, learning to write.
小说练习仓库，从零开始学习写作。

## 简介

这是一个个人写作练习仓库，用来记录从零开始学习小说创作的过程：练笔片段、短篇习作、读书笔记与写作心得都会沉淀在这里。

## 目录结构

- **卡片库**：阅读时拆出的可复用素材卡（结构 / 桥段 / 人物 / 冲突 / 场景 / 世界观 / 技法），存机制不存内容，规范见 `卡片库/README.md`
- **模板**：写作流程模板（场景写作流水线等）
- **练笔片段**：不定期的片段练习与拆片仿写（人物、场景、对话等专项训练）
- **短篇习作**：完整的短篇小说尝试
- **读书笔记**：阅读经典作品时的拆解与思考
- **写作心得**：技巧总结与复盘

## 说明

仓库内容会持续更新，所有习作均为练习性质，欢迎交流与指正。
