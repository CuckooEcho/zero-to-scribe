# 第10课完整教案：小人物与大罪恶

> **精读作品**：松本清张《砂器》（1960）/ 东野圭吾《白夜行》（1999）
> **所属流派**：社会派推理（时间跨度与命运感）
> **课时**：4学时（180分钟）
> **前置课程**：第9课（已掌握社会地图、日常崩溃、社会性动机）

---

## 一、课程目标

### 知识目标
1. 理解"时间跨度"在社会派推理中的叙事功能
2. 掌握"共犯关系"的书写技术（非面对面的协作犯罪）
3. 理解"美与恶并存"的复杂人物塑造

### 能力目标
1. 能设计一个跨越多年的犯罪时间线
2. 能写一段"时间褶皱"（在主线中插入过去片段）
3. 能塑造一个"让读者同情"的凶手

### 情感目标
1. 体会"命运"的重量——个人选择如何被时代和童年塑造
2. 理解"同情凶手"不等于"认同犯罪"

## 三、课前阅读指引（发给学生）

### 《白夜行》怎么读？

**第10课是"命运课"——学习如何写"被时间塑造的犯罪"。**

《白夜行》不是一本"找出凶手"的书——你知道凶手是谁。
它是一本"理解凶手"的书——你为什么理解他们，就是你为什么被震撼。

#### 阅读方法：时间追踪法

读《白夜行》时，你必须追踪时间：
1. **标记每个章节的时间**（哪一年？主角几岁？）
2. **标记每个犯罪的时间**（与主角的年龄有什么关系？）
3. **标记亮司和雪穗的"间接接触"**（他们没有直接见面，但如何协作？）

#### 带着这些问题读

1. **"童年"问题**：亮司和雪穗的童年创伤是什么？这个创伤如何影响了他们的一生？
2. **"共生"问题**：他们的关系是"爱情"吗？还是"互相利用"？还是"无法分离的命运共同体"？
3. **"间接"问题**：他们几乎没有直接见面，如何维持19年的共犯关系？这种"间接性"对叙事有什么效果？
4. **"光亮"问题**：书名是《白夜行》——"在白夜中行走"。这个隐喻是什么意思？谁有"太阳"？谁永远在"黑夜"？

#### 读完之后做一件事

**画出亮司和雪穗的"命运交织图"**：
```
时间轴：1973 ──────────────────────────→ 1992

亮司的事件线：A──B──C──D──E──F──G──H
                ↓  ↓  ↓  ↓  ↓  ↓  ↓
雪穗的事件线： a──b──c──d──e──f──g──h

连接线：哪些事件是"成对"的？（亮司做A，帮助了雪穗的a）
```

### 第1学时（45分钟）：时间跨度与命运感

#### 4.1 课程导入：从"瞬间"到"一生"（10分钟）

**教师开场**：
> "第9课我们学了'社会地图'——分析犯罪的社会根源。"
>
> "今天我们要进一步：不仅分析'社会的横截面'，还要分析'社会的时间轴'。"
>
> "一个人为什么会犯罪？不仅因为他现在处于什么社会位置，还因为他'经历了什么'才到达这个位置。"
>
> "松本清张的《砂器》和东野圭吾的《白夜行》，都跨越了多年。它们展示的不是'一个人在某一天犯罪'，而是'一个人如何在一生的过程中走向犯罪'。"

**板书**：
```
第10课：小人物与大罪恶
精读A：松本清张《砂器》（1960）
精读B：东野圭吾《白夜行》（1999）
主题：时间跨度、命运感、共犯关系
```

#### 4.2 时间跨度的叙事功能（15分钟）

**教师讲解**：
> "为什么有些推理小说要跨越多年？"
> "时间跨度不是'长'就好，它必须有叙事功能。"

**板书：时间跨度的三种叙事功能**
```
功能1：展示"慢性崩溃"
→ 不是某一天突然犯罪，而是多年的压力积累
→ 案例：《砂器》——主人公从贫苦少年到成功人士，每一步都踩着秘密

功能2：制造"命运感"
→ 让读者感到"他/她逃不掉"
→ 案例：《白夜行》——童年的创伤像诅咒，跟随一生

功能3：创造"反讽"
→ 时间让"成功"变成"讽刺"
→ 案例：《砂器》——主人公越成功，秘密越危险
```

**"时间褶皱"技术**：
```
主线叙事（现在）
───────┬────────┬────────┬────────
       ↓        ↓        ↓
   过去片段A  过去片段B  过去片段C
   （童年）   （青年）   （某年的事件）

插入原则：
1. 过去片段必须解释现在的某个行为
2. 插入的时机：读者对现在的行为产生好奇时
3. 效果：让读者"恍然大悟"——"原来他这样做是因为童年那件事"
```

#### 4.3 《砂器》与《白夜行》的对比（10分钟）

**教师讲解**：
> "两本书都写'小人物与大罪恶'，但角度不同。"

**板书：《砂器》vs《白夜行》**
```
┌─────────────────┬─────────────────┐
│    《砂器》      │   《白夜行》     │
├─────────────────┼─────────────────┤
│ 作者：松本清张   │ 作者：东野圭吾   │
│ 年代：1960       │ 年代：1999       │
├─────────────────┼─────────────────┤
│ 时间跨度：约20年 │ 时间跨度：19年   │
├─────────────────┼─────────────────┤
│ 主角：和贺英良   │ 主角：亮司、雪穗 │
│ （从贫苦到成功） │ （从童年到成年） │
├─────────────────┼─────────────────┤
│ 核心关系：父子   │ 核心关系：共生   │
│ （弑父的秘密）   │ （童年的创伤）   │
├─────────────────┼─────────────────┤
│ 叙事方式：       │ 叙事方式：       │
│ 警察追踪+主角回忆│ 双线并行         │
│                 │ （亮司线+雪穗线）│
├─────────────────┼─────────────────┤
│ 情感效果：       │ 情感效果：       │
│ 同情+悲凉        │ 同情+震撼+空虚   │
└─────────────────┴─────────────────┘
```

**共同主题**：
> "两本书的共同主题：'成功'是'罪恶'的代价。"
> "主人公表面上获得了社会认可的成功，但内心被秘密腐蚀。"
> "这种'美与恶'的并存，是社会派最深刻的主题。"

### 第2学时（45分钟）：共犯关系的书写

#### 4.4 "间接共犯"的技术（20分钟）

**教师讲解**：
> "《白夜行》最独特的技术：亮司和雪穗几乎不见面，却协作了19年。"
> "这种'间接共犯'关系，怎么写？"

**板书：共犯关系的类型**
```
直接共犯：面对面协作
→ A和B一起计划、一起执行
→ 常见于：本格推理中的集体犯罪
→ 难点：如何解释两人之间的"信任"？

间接共犯：不见面协作
→ A和B通过物品、信息、第三方传递协作
→ 常见于：社会派推理中的长期共犯
→ 难点：如何维持长期的"不面对面"关系？

《白夜行》的间接共犯技术：
1. 童年契约：共同的创伤 = 天然的信任基础
2. 信息同步：通过报纸、传闻、第三方传递信息
3. 行动互补：亮司负责"暗"（犯罪），雪穗负责"明"（社交）
4. 物品传递：通过约定地点、秘密信箱等方式交换信息
5. 同步行为：在不同地点做同一件事，形成"远程共犯"
```

**教学要点**：
> "写间接共犯的关键：让读者相信'他们不需要见面也能合作'。"
> "这种'相信'来自两点："
> "1. 他们有'共同的目标'（或共同的敌人）"
> "2. 他们有'共享的记忆'（不需要语言就能理解对方）"

#### 4.5 "美与恶"的并存（15分钟）

**教师讲解**：
> "社会派的高级技巧：让读者对凶手产生'同情'甚至'admiration'。"
> "这不是美化犯罪，而是展示人性的复杂。"

**板书：复杂人物的塑造原则**
```
"美与恶"并存的塑造方法：

1. 展示凶手的"努力"
→ 他/她不是天生邪恶，而是在极端困境中挣扎求生
→ 例如：《白夜行》中雪穗的学习、社交、事业——她比任何人都努力

2. 展示凶手的"牺牲"
→ 他/她的犯罪不是为了自己，而是为了保护某人
→ 例如：《白夜行》中亮司的所有犯罪都是为了雪穗

3. 展示凶手的"脆弱"
→ 在冷酷的外表下，有无法愈合的伤口
→ 例如：《砂器》中主人公对音乐的执着——那是他唯一的"干净"的东西

4. 展示凶手的"孤独"
→ 没有人理解他/她，他/她无法向任何人倾诉
→ 这种孤独让读者产生同情

危险边界：
→ 同情 ≠ 认同
→ 让读者"理解"凶手，不等于让读者"支持"犯罪
→ 在故事结尾，必须让读者感到"悲伤"而非"痛快"
```

#### 4.6 课堂讨论：你同情凶手吗？（10分钟）

**讨论问题**：
1. 读完《白夜行》后，你对亮司和雪穗的感受是什么？
2. 你觉得他们是"坏人"吗？为什么？
3. 如果你的童年经历了他们所经历的，你会怎么做？
4. 作者让你同情凶手，这是"操纵"还是"艺术"？

### 第3学时（45分钟）：时间线与"时间褶皱"写作

#### 4.7 时间线设计练习（15分钟）

**教师讲解**：
> "设计一个跨越多年的犯罪故事，首先要设计'时间线'。"

**板书：时间线设计模板**
```
犯罪时间线设计

原初创伤（童年/青年）：
→ 发生了什么？
→ 对主角的心理影响是什么？

潜伏期（数年）：
→ 主角如何"正常"生活？
→ 什么维持了他/她的"正常"？

第一次犯罪（触发点）：
→ 发生了什么，让主角打破了底线？
→ 这次犯罪是"冲动"还是"计划"？

犯罪升级（多次）：
→ 每次犯罪如何比上一次更"大"？
→ 主角的心理如何变化？（麻木？兴奋？恐惧？）

最终暴露/结局：
→ 是什么导致了最终的暴露？
→ 结局是"审判"还是"解脱"？
```

#### 4.8 "时间褶皱"仿写练习（20分钟）

**练习题目**：

> **任务**：写一段"时间褶皱"（800字）。
>
> **结构**：
> **主线（现在）：200字**
> - 主角现在是一个成功的中年人（企业家/医生/教授）
> - 描写他/她的一个日常场景
> - 但有一个"小异常"（例如：看到某个物品时的异常反应）
>
> **褶皱1（过去，15年前）：200字**
> - 主角年轻时的某个关键事件
> - 这个事件解释了现在的"异常反应"
>
> **回到主线（现在）：200字**
> - 主角继续日常，但读者现在理解了异常的原因
> - 主角做出了一个与过去相关的决定
>
> **褶皱2（过去，童年）：200字**
> - 主角童年的原初创伤
> - 这个创伤解释了年轻时的关键事件
>
> **写作时间**：15分钟

**学生写作（15分钟）**

**互评（5分钟）**：
- 交换作品，检查：
  1. "褶皱"是否解释了主线的"异常"？
  2. 时间跳转是否清晰？（读者能否分辨"现在"和"过去"？）
  3. 读完之后，是否对主角有了新的理解？

#### 4.9 共犯关系设计（10分钟）

**练习**：
> 设计一个"间接共犯"关系（200字）：
> - 两个人不直接见面
> - 他们通过某种方式协作犯罪（或共同隐藏秘密）
> - 他们的"信任基础"是什么？（童年记忆？共同目标？共同敌人？）

### 第4学时（45分钟）：综合练习与总结

#### 4.10 课堂练习：命运感短篇（20分钟）

**练习题目**：

> **要求**：

**互评（5分钟）**：
- 评估：主角的"崩溃"是否有说服力？

## 五、课后作业

### 作业1：时间线完善（必做）

> 为你的期中作品（或新构思）设计一个"犯罪时间线"：
> - 原初创伤是什么？
> - 潜伏期有多长？
> - 第一次犯罪的触发点是什么？
> - 犯罪如何升级？
> - 结局是什么？
>
> 用表格形式呈现，至少5个时间点。

### 作业2：共犯关系设计（必做）

> 设计一个"间接共犯"关系（500字）：
> - 两个人的身份和关系
> - 他们的"信任基础"
> - 他们的协作方式（不见面）
> - 他们各自的"代价"（为了维持共犯关系，各自失去了什么？）

### 作业3：美与恶场景（选做）

> 写一个500字的场景：展示一个凶手的"美"的一面。
> 要求：
> - 不提及任何犯罪
> - 只展示他/她的某个"纯粹"的爱好或行为
> - 让读者感到"如果他/她没有犯罪，会是一个多好的人"

## 七、教师备查资料

### 7.1 《白夜行》详细拆解（教师参考）

**核心结构**：双线并行
- 亮司线：在黑暗中行动，保护雪穗
- 雪穗线：在光明中上升，利用亮司

**时间跨度**：1973-1992，19年

**关键技巧**：
- 两人几乎不直接见面
- 通过犯罪协作维持关系
- 每次犯罪都是"互利的"

**结局设计**：
- 亮司死亡，雪穗继续生活
- "她一次都没有回头"——最冷酷的结局

### 7.2 常见学生问题与应对

| 学生问题 | 教师应对 |
|---------|---------|
| "我的时间跨度故事写成了'流水账'。" | 回应：时间跨度不需要写每一年。只写"关键转折点"，用"时间褶皱"连接。 |
| "我想让读者同情凶手，但读者只觉得凶手'恶心'。" | 回应：可能你的"恶"写得太多，"美"写得太少。在展示犯罪之前，先展示凶手的"正常"和"脆弱"。 |
| "我的共犯关系太依赖'巧合'了。" | 回应：共犯关系需要"设计"而非"巧合"。给他们一个"必须合作"的理由（共同的敌人、共同的秘密）。 |
