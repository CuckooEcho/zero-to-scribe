# 第8课完整教案：期中本格综合演练

> **课程类型**：创作实践课（非阅读拆解课）
> **课时**：4学时（180分钟）
> **前置课程**：第1-7课（本格基础模块全部完成）
> **核心任务**：学生综合运用前7课技法，独立完成一篇3000-5000字的本格推理中篇

---

## 一、课程目标

### 知识目标
1. 理解"创作流程"与"阅读分析"的区别——从"拆别人"到"建自己"
2. 掌握从"大纲→第一章→完整作品"的写作流程
3. 理解"创作笔记"的功能——记录设计思路，便于他人理解

### 能力目标
1. 能在4学时内完成一篇结构完整的本格推理中篇（3000-5000字）
2. 能为自己的作品附500字创作笔记（说明使用的技法和设计思路）
3. 能按照评分标准互评同学作品

### 情感目标
1. 体验"从零到一"的创作过程——克服"写不出来"的恐惧
2. 体会"被读者阅读"的感受——理解作者与读者的关系

## 三、课前创作指引（发给学生）

### 期中作品创作指南

#### 作品要求

**字数**：3000-5000字（不含创作笔记）

**类型**：本格推理（必须使用第1-7课中的至少3项技法）

**结构要求**：
- 必须有完整的"谜面→调查→解答"三段式结构
- 必须有至少1个核心诡计（密室/不在场证明/身份诡计/逻辑谜题等）
- 解答必须依赖文中已展示的线索（公平性）

**附：创作笔记（500字）**
- 说明你的灵感来源
- 列出你使用的技法及其来源（第几课）
- 说明核心诡计的设计思路
- 说明线索布置策略
- 说明你在创作中遇到的困难及如何克服

#### 创作流程建议

**阶段1：确定核心（1小时）**
- 选择一个"让你兴奋"的谜面
- 不要追求"最复杂"，追求"最清楚"
- 核心诡计可以用一句话说明

**阶段2：建立结构（1小时）**
- 确定三段式的比例（建议：谜面20%、调查50%、解答30%）
- 列出"已知信息清单"（至少8条线索）
- 确定红鲱鱼的位置（至少2条）

**阶段3：写作（3-5小时）**
- 先写解答篇（确保逻辑自洽）
- 再写谜面篇（确保吸引力）
- 最后调整线索分布（确保公平性）

**阶段4：检查（1小时）**
- 使用"创作检查清单"逐项检查
- 让朋友读一遍，看他能否推理出真相

#### 常见困难与应对

| 困难 | 应对 |
|------|------|
| "想不出复杂的诡计" | 不要复杂。一个简单的诡计，写清楚，比重大的诡计写糊涂要好。 |
| "写到一半发现逻辑不通" | 停下来，画逻辑树。找出断裂的环节，修补或重写。 |
| "解答太容易被猜到" | 增加红鲱鱼，或把关键线索伪装成背景信息。 |
| "解答太难，自己都糊涂了" | 简化。奥卡姆剃刀：最简单的解答往往是最好的。 |
| "写到一半不想写了" | 这是正常的。休息10分钟，然后继续。创作就是与放弃的冲动对抗。 |

## 四、课堂流程（4学时，180分钟）

---

### 第1学时（45分钟）：创作启动与时间管理

#### 4.1 课程导入：从读者到作者（5分钟）

**教师开场**：
> "前7课，你们是读者——拆解别人的作品，学习别人的技法。"
>
> "今天，你们是作者。"
>
> "这是完全不同的心态。作为读者，你们可以挑剔；作为作者，你们必须负责。"
>
> "你们写的每一个字，都会被别人阅读、分析、评判。"
>
> "但这正是创作的乐趣——你不再是被动地接受故事，你是主动地创造故事。"

#### 4.2 时间管理：4小时的写作马拉松（10分钟）

**教师讲解**：
> "4小时写3000-5000字，平均每小时1000字左右。"
> "这听起来很多，但如果你们已经准备好了大纲和第一章，是完全可行的。"

**板书：时间分配建议**
```
4学时（180分钟）时间分配：

第1学时（45分钟）：
├── 导入与答疑（15分钟）
├── 快速修改大纲（15分钟）
└── 开始写作（15分钟）

第2学时（45分钟）：
└── 集中写作（45分钟）
    → 目标：完成谜面篇 + 调查篇的大部分

课间休息（10分钟）

第3学时（45分钟）：
└── 集中写作（45分钟）
    → 目标：完成调查篇 + 解答篇

第4学时（45分钟）：
├── 收尾与修改（15分钟）
├── 创作笔记（15分钟）
└── 互评与提交（15分钟）
```

**写作节奏建议**：
- 不要回头修改——先写完，再修改
- 如果卡壳超过5分钟，跳过这一段，继续写后面
- 用"【待补充】"标记暂时写不出的地方，继续往前

#### 4.3 "急救包"——卡壳时的快速提示（15分钟）

**教师发放"急救卡"**（可打印，学生可随时查看）：

```
╔═══════════════════════════════════════════════╗
║            创作急救卡                         ║
╠═══════════════════════════════════════════════╣
║                                               ║
║ 【谜面卡壳】不知道写什么谜面？               ║
║ → 选一个日常物品（杯子、钥匙、雨伞）          ║
║ → 问：它出现在不该出现的地方，为什么？       ║
║                                               ║
║ 【调查卡壳】侦探不知道问什么？               ║
║ → 让侦探问：时间/地点/人物/动机              ║
║ → 让证人给出"多余的细节"（那是线索）         ║
║                                               ║
║ 【解答卡壳】不知道怎么揭晓真相？             ║
║ → 回到"已知信息清单"                         ║
║ → 找出一条"被忽视"的线索                     ║
║ → 从这条线索出发，倒推5步                    ║
║                                               ║
║ 【逻辑卡壳】发现解答有漏洞？                 ║
║ → 不要硬补，换一个更简单的解答               ║
║ → 或：把漏洞变成"红鲱鱼"                     ║
║                                               ║
║ 【字数卡壳】写不到3000字？                   ║
║ → 增加对话（对话可以快速增加字数）            ║
║ → 增加环境描写（氛围也是推理的一部分）       ║
║ → 增加假说讨论（侦探与助手的讨论）            ║
║                                               ║
╚═══════════════════════════════════════════════╝
```

#### 4.4 快速答疑与启动写作（15分钟）

**教师快速回答学生问题**（针对课前构思表中的困难）：
- "我的大纲还需要修改吗？" → "可以快速修改15分钟，然后必须开始写。"
- "我可以写我之前构思的故事吗？" → "可以，只要符合要求。"
- "如果4小时写不完怎么办？" → "尽量写完。如果实在写不完，提交已完成的部分+续写计划。"

**启动信号**：
> "好，现在开始。计时器启动。第1学时的15分钟写作时间，开始！"

---

### 第2学时（45分钟）：集中写作（谜面篇+调查篇）

#### 4.5 写作阶段：谜面篇+调查篇（45分钟）

**教师角色**：
- 巡视教室，观察学生状态
- 对卡壳的学生提供"急救卡"提示
- 不主动打扰写作中的学生
- 记录共性问题（第4学时统一讲解）

**常见场景与应对**：

| 场景 | 教师应对 |
|------|---------|
| 学生盯着屏幕不动超过5分钟 | 轻声询问卡壳点，提供"急救卡"对应提示 |
| 学生频繁删除重写 | 提醒："先写完，再修改。用【待补充】跳过。" |
| 学生写得太快（可能质量低） | 观察即可，不干预。速度不是评判标准。 |
| 学生写得太慢（可能过于纠结） | 提醒："距离目标字数还有___字，需要加快节奏。" |

**计时提醒**：
- 第15分钟："还有30分钟。目标：完成谜面篇。"
- 第30分钟："还有15分钟。开始写调查篇。"
- 第45分钟："第2学时结束。保存你的文件。休息10分钟。"

### 第3学时（45分钟）：集中写作（调查篇+解答篇）

#### 4.6 写作阶段：调查篇+解答篇（45分钟）

**教师角色**：同上

**计时提醒**：
- 第15分钟："还有30分钟。目标：完成调查篇。"

### 第4学时（45分钟）：收尾、创作笔记与互评

#### 4.7 收尾与快速修改（15分钟）

**教师引导**：
> "现在进入最后阶段。你还有15分钟来收尾和修改。"
>
> "不要大改。只做以下事情："

**快速修改清单**：
```
□ 检查开头和结尾是否呼应
□ 检查所有【待补充】是否已补充（或删除）
□ 检查字数（3000-5000字？）
□ 检查是否有明显的错别字
□ 检查核心诡计是否在解答中被清晰说明
```

#### 4.8 创作笔记（15分钟）

**教师引导**：
> "现在写创作笔记。这不是可选的，是必须提交的。"
>
> "创作笔记帮助读者（我和你的同学）理解你的设计意图。"

**创作笔记模板**（500字）：
```
创作笔记

1. 灵感来源（100字）
   这个作品的灵感来自：__________

2. 使用的技法（150字）
   我在本作品中使用了以下技法：
   - __________（来自第___课）
     具体运用：__________
   - __________（来自第___课）
     具体运用：__________
   - __________（来自第___课）
     具体运用：__________

3. 核心诡计设计（150字）
   我的核心诡计是：__________
   设计思路：__________
   公平性检验：所有关键线索都在解答前展示了吗？□是 □否

4. 创作困难与克服（100字）
   我在创作中遇到的最大困难是：__________
   我是如何克服的：__________
```

#### 4.9 互评与提交（15分钟）

**互评规则**：
1. 学生两两交换作品（电子版或打印版）
2. 使用"评分标准表"进行评分
3. 5分钟阅读 + 评分
4. 互评后，作品提交给教师

**评分标准表**：

| 评分项 | 分值 | 评价标准 | 得分 |
|--------|------|---------|------|
| 结构完整性 | 20分 | 是否有清晰的三段式结构？比例是否合理？ | |
| 核心诡计 | 20分 | 诡计是否清晰？是否有创意？是否公平？ | |
| 线索布置 | 15分 | 线索是否足够？是否有红鲱鱼？是否回收？ | |
| 逻辑自洽 | 15分 | 解答是否能解释谜面？有无自相矛盾？ | |
| 可读性 | 15分 | 语言是否流畅？人物是否鲜明？氛围是否到位？ | |
| 创作笔记 | 15分 | 是否清晰说明技法来源和设计思路？ | |
| **总分** | **100分** | | |

**互评后的快速分享**（如果时间允许，3分钟）：
- "谁的作品让你最惊讶？"
- "谁的诡计你最想继续读下去？"

## 六、教师评估指南

### 6.1 作品评分标准（教师用）

| 等级 | 分数 | 描述 |
|------|------|------|
| 优秀 | 90-100 | 结构完整，诡计有创意且公平，逻辑严密，可读性强，创作笔记清晰 |
| 良好 | 80-89 | 结构完整，诡计清晰，逻辑基本自洽，可读性良好 |
| 合格 | 70-79 | 结构基本完整，有核心诡计，但逻辑有 minor 漏洞 |
| 待改进 | 60-69 | 结构不完整，或诡计不清晰，或逻辑有重大漏洞 |
| 不合格 | <60 | 未达到基本要求 |

### 6.2 常见作品问题与反馈模板

| 问题 | 反馈模板 |
|------|---------|
| 谜面不清晰 | "读者需要更清楚地知道'发生了什么'。建议在开头用200字明确异常现象。" |
| 线索不足 | "解答依赖的线索在文中不够明显。建议让侦探在调查阶段更明确地提到这些线索。" |
| 逻辑跳跃 | "从X到Y的推理缺少中间步骤。建议补充：'因为A，所以B；因为B，所以C。'" |
| 解答太简单 | "诡计本身不错，但揭示方式太直接。建议增加一个'假说否定'的环节。" |
| 解答太复杂 | "诡计过于复杂，读者可能跟不上。建议简化核心机制，或增加'解释性对话'。" |
| 人物扁平 | "人物的功能性太强，缺乏个性。建议给侦探或凶手添加一个小习惯或口头禅。" |

### 6.3 课堂时间备用方案

如果学生写作速度差异大：
- 提前完成的学生：可以帮助同学互评，或开始写创作笔记
- 严重滞后的学生：允许提交"已完成部分+续写计划"，不降低评分

## 七、延伸与拓展

### 作品发表建议

鼓励学生将期中作品发表到以下平台：
- 学校文学社团刊物
- 网络推理小说论坛
- 个人博客/公众号
- 推理小说比赛（如国内的新人推理小说奖）

### 优秀作品展示

选择3-5篇优秀作品，在班级/学校范围内展示。
展示形式：
- 匿名展示（只展示作品，不展示作者）
- 全班投票"最佳诡计""最佳氛围""最佳反转"
- 获奖作品附教师点评
