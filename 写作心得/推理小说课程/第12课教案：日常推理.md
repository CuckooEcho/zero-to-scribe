# 第12课完整教案：日常推理

> **精读作品**：米泽穗信《冰菓》系列选篇 / 北村薰《空中飞马》
> **所属流派**：日常推理（推理小说的"轻量版"）
> **课时**：4学时（180分钟）
> **前置课程**：第9-11课（社会派与冷硬派模块）
> **模块定位**：第二编第4课（本模块最后一课）

---

## 一、课程目标

### 知识目标
1. 理解"日常推理"的定义与边界——没有犯罪，只有"在意的小事"
2. 掌握"节能侦探"的塑造（被动卷入、低能耗、高观察力）
3. 理解"平凡的异常"——日常之谜的谜面设计

### 能力目标
1. 能设计一个"日常之谜"（无犯罪，只有让人在意的小事）
2. 能写一段"慢节奏"的推理场景（对话驱动、观察细腻、无紧迫感）
3. 能在日常场景中预埋"异常线索"

### 情感目标
1. 体会"日常中的美"——推理小说可以温柔、可以安静
2. 理解"好奇心"本身就是推理的驱动力——不需要谋杀

## 三、课前阅读指引（发给学生）

### 日常推理怎么读？

**第12课是"减法课"——学习如何用"更少"的元素写出"同样有趣"的推理。**

日常推理的核心悖论：
- 没有谋杀
- 没有密室
- 没有不在场证明
- 但它仍然是推理小说

#### 阅读方法：好奇心追踪法

读日常推理时，不要寻找"犯罪"，要寻找"不对劲"：
1. 什么东西出现在不该出现的地方？
2. 什么人的行为和平时不同？
3. 什么规律被打破了？
4. 什么"小事"让你感到"在意"？

#### 带着这些问题读

1. **"谜面"问题**：《冰菓》的谜面是什么？（提示：不是"谁杀了谁"，而是"为什么"或"怎么回事"。）
2. **"侦探"问题**：折木奉太郎为什么被称为"节能侦探"？他的"节能"是懒惰还是智慧？
3. **"解答"问题**：日常推理的解答是否比本格推理的解答"简单"？简单是否等于"无趣"？
4. **"价值"问题**：如果没有犯罪，推理小说的"价值"在哪里？

#### 读完之后做一件事

**列出"你的日常之谜"**：
> 在生活中，有什么"小事"让你长期感到好奇？
> 例如：
> - 为什么便利店的某个货架总是空的？
> - 为什么某人的伞总是放在同一个位置？
> - 为什么图书馆的某本书永远借不到？
>
> 选择其中一个，写出它的"谜面"（100字）和"你的猜测"（100字）。

## 四、课堂流程（4学时，180分钟）

### 第1学时（45分钟）：日常推理的定义与边界

#### 4.1 课程导入：推理小说的"轻量化"（10分钟）

**教师开场**：
> "前11课，我们学的推理小说都涉及'犯罪'——谋杀、盗窃、失踪。"
>
> "今天，我们要学习一种完全不同的推理小说：'日常推理'。"
>
> "它的核心问题是：没有犯罪，推理小说还成立吗？"
>
> "答案是：成立。因为推理的本质不是'抓凶手'，而是'解释异常'。"
>
> "而生活中，充满了'异常'。"

**板书**：
```
第12课：日常推理
精读：米泽穗信《冰菓》（2001-）/ 北村薰《空中飞马》（1989）
主题：无犯罪的推理、节能侦探、平凡的异常

日常推理的定义：
- 没有犯罪（或犯罪极轻微）
- 谜面是"让人在意的小事"
- 解答依赖观察、逻辑、对人性的理解
- 节奏慢、氛围轻松、对话驱动
```

#### 4.2 日常推理的"谜面"类型（15分钟）

**板书：日常推理的谜面分类**
```
日常推理的六大谜面类型：

1. "为什么在这里？"
   → 某物出现在不该出现的地方
   → 例：图书馆的书出现在教室

2. "为什么是这样？"
   → 某物的状态异常
   → 例：黑板上的字被擦掉了，但没人承认

3. "为什么是他/她？"
   → 某人的行为异常
   → 例：某人今天突然早到了

4. "为什么现在？"
   → 某事发生的时间异常
   → 例：某人只在雨天出门

5. "为什么没有？"
   → 某物/某事应该存在但不存在
   → 例：教室里的花瓶每天换花，但今天没有

6. "多了什么？"
   → 某物/某事不应该存在但存在
   → 例：储物柜里多了一张匿名纸条
```

**日常推理 vs 本格推理的谜面对比**：

| 本格推理 | 日常推理 |
|---------|---------|
| "谁杀了X？" | "为什么X的伞是湿的？" |
| "凶手如何离开密室？" | "为什么教室的门锁坏了？" |
| "谁在咖啡里下了毒？" | "为什么某人今天没喝咖啡？" |
| "死者的遗言是什么意思？" | "黑板上被擦掉的字是什么？" |

#### 4.3 "节能侦探"折木奉太郎（10分钟）

**教师讲解**：
> "日常推理的侦探与传统侦探完全不同。"
> "他们不是'主动寻找谜题'，而是'被动卷入谜题'。"

**板书：折木奉太郎的"节能主义"**
```
折木奉太郎的座右铭：
"不必要的事不做，必要的事尽快做。"

传统侦探：主动、好奇、精力充沛
→ "又有案子了！让我来！"

节能侦探：被动、节能、低能耗
→ "为什么我要管这件事？"
→ "好吧，既然你问了，那我就说一下。"

节能侦探的魅力：
1. 反差感：看似冷漠，实则敏锐
2. 亲近感：像你我一样，不想惹麻烦
3. 惊喜感：当他说出解答时，你会"啊？原来他一直在观察"

节能侦探的推理方式：
→ 不跑现场、不收集证据
→ 坐在原地，通过对话和观察得出结论
→ 推理速度快，但介入速度慢
```

### 第2学时（45分钟）：《冰菓》与《空中飞马》拆解

#### 4.4 日常推理的"慢节奏"（15分钟）

**教师讲解**：
> "日常推理的节奏是'慢'的。"
> "这种'慢'不是'无聊'，是'沉浸'。"

**板书：日常推理的节奏设计**
```
日常推理的节奏公式：

谜面出现：慢（可能用整整一章铺垫）
→ 不是"突然发生"，而是"慢慢浮现"
→ 例：某人注意到"最近总少一本书"，
     先是偶尔想到，然后越来越在意

调查过程：更慢（对话、观察、猜测）
→ 没有紧迫感，没有倒计时
→ 侦探和助手（或朋友）坐在教室里、
   咖啡馆里、公园里讨论
→ 讨论内容可能涉及回忆、人际关系、
   学校文化、历史背景

解答时刻：快（几句话点破）
→ 没有"召集所有人"的戏剧场面
→ 可能是在放学路上，随口说出
→ 但听者会"恍然大悟"

关键原则：
日常推理的快感来自"积累"而非"冲击"
→ 谜面的"小"与解答的"巧妙"形成反差
```

#### 4.5 "平凡的异常"设计（15分钟）

**教师讲解**：
> "设计日常推理的谜面，关键是找到'平凡的异常'。"
> "不是'惊天动地的大事'，是'每天看到但从未注意的小事'。"

**板书：设计"平凡的异常"的方法**
```
方法1：规律性打破
→ 某人/某物有固定的规律，某一天打破了
→ 例：某人每天带同一款便当，今天没带

方法2：位置异常
→ 某物出现在了不该出现的地方
→ 例：教室里的垃圾桶里有一张不该在那里的纸

方法3：时间异常
→ 某事发生的时间与平时不同
→ 例：某人平时下午离开，今天早上就离开了

方法4：数量异常
→ 某物的数量与平时不同
→ 例：粉笔盒里多了一支彩色粉笔

方法5：状态异常
→ 某物的状态与平时不同
→ 例：门锁平时是坏的（总是锁不上），
     但今天竟然锁上了

关键原则：
异常必须"足够小"——小到你通常会忽略
但"足够具体"——具体到你一旦注意到就无法忘记
```

#### 4.6 课堂练习：日常之谜设计（15分钟）

**练习题目**：

> **任务**：设计3个"日常之谜"。
>
> **要求**：
> 1. 无犯罪、无暴力、无失踪
> 2. 谜面必须是你生活中可能出现的"小事"
> 3. 每个谜面附2种可能的解释（其中一种是"真相"）
>
> **示例格式**：
> 谜面：图书馆的《冰菓》总是被借走，但还书记录显示没有人借过。
> 解释A：图书馆系统故障。
> 解释B（真相）：图书管理员自己拿走了，因为她每晚下班后在馆内阅读。
>
> **写作时间**：10分钟

**学生设计（10分钟）**

**分享（5分钟）**：
- 全班投票：哪个"日常之谜"最让你"在意"？
- 讨论：为什么这个谜面吸引人？

### 第3学时（45分钟）：日常推理的写作技法

#### 4.7 "对话驱动"的推理场景（20分钟）

**教师讲解**：
> "日常推理的核心场景不是'调查现场'，是'对话'。"
> "侦探通过对话获取信息，通过对话推理，通过对话解答。"

**板书：对话驱动推理的写作技巧**
```
日常推理的对话原则：

1. 信息密度
   → 每段对话至少包含一条"信息"或"线索"
   → 但同时要有"闲聊"（否则太干）
   → 比例：70%闲聊 + 30%信息

2. 角色功能
   → 侦探：提问、观察、总结
   → 助手：提供信息、提出假说、代表读者提问
   → 其他人：提供线索、制造红鲱鱼、增加氛围

3. 节奏控制
   → 不要连续问太多问题（像审问）
   → 用"回忆""猜测""吐槽"打断逻辑链
   → 让对话"自然"——像朋友聊天

4. 推理的"展示"
   → 不要在对话中直接说"所以凶手是X"
   → 要让侦探"慢慢推导出结论"，
     助手（和读者）跟随每一步
```

**示范：对话驱动的推理场景**

**反面示例**（太直接）：
```
A："你为什么今天没带便当？"
B："因为我妈妈生病了。"
A："所以你今天去食堂了？"
B："是的。"
A："但食堂今天没开。所以你去了便利店。
    便利店的收据显示你买了三明治。
    三明治的包装纸上有一家便利店的logo，
    但那logo是旧版，说明那家店三年前就关门了。
    所以你在撒谎。"
```
→ 问题：太像审问，没有对话感。

**正面示例**（自然）：
```
A："你今天没带便当？"
B："嗯，我妈今天没空做。"
A："那你去食堂了？"
B："去了，但排队太长，就去了便利店。"
A："哪家？"
B："车站前面那家。"
A："哦……那家啊。"（停顿）"我记得那家
    三年前就换成连锁品牌了，logo也换了。
    你看到的还是旧logo？"
B："……"
```
→ 效果：像聊天，但信息在流动。

#### 4.8 课堂练习：对话场景仿写（15分钟）

**练习题目**：

> **任务**：写一段400字的"对话驱动推理"场景。
>
> **设定**：
> - 地点：学校教室/图书馆/咖啡馆
> - 人物：2-3人（其中1人是"节能侦探"）
> - 谜面：某件"日常小事"让人在意
> - 要求：
>   1. 通过对话推进推理（不要 narration 解释）
>   2. 包含至少1条线索的"自然流露"
>   3. 包含至少1个"错误假说"（被对话否定）
>   4. 结尾处侦探"随口"说出解答
>
> **写作时间**：10分钟

**学生写作（10分钟）**

**互评（5分钟）**：
- 这段对话是否"自然"？（像朋友聊天吗？）
- 线索是否"隐藏"在对话中？（不是直接陈述？）

#### 4.9 日常推理的"价值"（10分钟）

**教师讲解**：
> "有人会问：没有犯罪，推理小说还有什么'价值'？"
> "答案是：日常推理的价值在于'重新发现日常'。"

**板书：日常推理的"价值"**
```
日常推理的三重价值：

1. 观察力的训练
   → 让你注意平时忽略的细节
   → 让你对"规律"和"异常"更敏感

2. 同理心的培养
   → 每个"异常"背后都有一个人的故事
   → 理解"为什么他会这样做"

3. 生活的美化
   → 证明日常生活本身就充满趣味
   → 不需要谋杀，也能有"推理的快感"

日常推理的局限：
→ 不适合追求"强烈刺激"的读者
→ 不适合喜欢"复杂诡计"的读者
→ 但适合喜欢"安静思考"的读者
```

## 七、教师备查资料

### 7.1 日常推理的发展（教师参考）

**起源**：
- 1980年代末，北村薰《空中飞马》系列
- 1990年代，米泽穗信《冰菓》系列
- 特点：回归校园、回归日常、回归"小"

**与本格的关系**：
- 日常推理是本格的"轻量化"
- 保留了"逻辑推导"的核心
- 去掉了"犯罪"和"紧迫感"

### 7.2 常见学生问题与应对

| 学生问题 | 教师应对 |
|---------|---------|
| "日常推理太无聊了，没有刺激感。" | 回应：日常推理的快感来自"积累的惊喜"——谜面越小，解答越巧妙，反差越大。如果你习惯了本格的"冲击"，需要调整心态。 |
| "我想不出'让人在意的小事'。" | 回应：从你自己的生活中找。今天有什么"不对劲"吗？某人迟到？某物位置变了？这些都可以是谜面。 |
| "日常推理的解答太简单了。" | 回应：简单不等于"无趣"。关键在于"伪装"——让读者明明看到了线索，却没想到。这是和本格一样的技法。 |
