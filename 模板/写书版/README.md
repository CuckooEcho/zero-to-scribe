# 写书版 · 使用流程

与 `拆书版/` 的区别：拆书时章已经切好（行=章）；**自己写书时章不存在，是最后一步才切出来的包装**。
核心原则：**事件是骨，场景是肉，章是皮**。

```
构思期 → 事件表      一卷 5–8 行，每行一个事件（对应分形三幕卡的「每卷 5 问」）
展开期 → 场景表      每个事件拆成 2–4 个场景，编号 E04-S2（事件04-场景2）
包装期 → 切章        看着「钩子」列归拢成章，一章一个钩子，切在情绪压强最高处
```

- 一个事件通常跨 1–5 章（一个小高潮约 3–10 章），跨章用共享事件编号表示
- 伏笔表、人物状态表两个阶段通用，见 `../拆书版/`，把"章号"理解为事件/场景编号即可
- 参考：[[../../卡片库/结构卡-分形三幕]]
