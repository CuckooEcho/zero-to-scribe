# 事件表（构思期 · 卷骨架）

每行一个**事件**：一次完整的「目标 → 对抗 → 结果」，价值发生一次大转变（麦基说的序列/sequence）。
一卷 5–8 个事件为宜；填不出某列，说明这个事件还没想透。

| 事件编号 | 事件名 | 三幕位置 | 目标（谁想要什么） | 冲突（对手/阻碍） | 结果 | 价值转变 | 场景数 | 卷尾钩子贡献 |
|---------|--------|---------|-------------------|------------------|------|---------|-------|-------------|
| E01     |        |         |                   |                  |      |         |       |             |

## 填写规范

- **三幕位置**：本卷内部的定位——开场 / 激励事件 / 中点转折 / 低谷 / 高潮 / 收束（对应救猫咪节拍，卷级粒度）
- **价值转变**：+ 向好 / - 向坏 / ± 反转。没有价值转变的事件不是事件，是过渡段
- **场景数**：展开期的计划，2–4 个场景一个事件
- **卷尾钩子贡献**：本事件为下一卷留下了什么（新敌人 / 新悬念 / 新目标）
- 全部填完后自查：相邻事件的价值转变应当正负交替（连续三个 + 说明太顺，连续三个 - 说明太丧）
