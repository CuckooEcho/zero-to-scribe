# 场景写作流水线（电影式）

输入一句话事件核，输出一场戏。每一步"为什么这么接"都有规则。

## 第 0 阶段：剧本定稿

写不下来就不许开工的三件事：

1. **事件核**：一句话
2. **戏的功能**：这场戏在整篇里干什么
3. **情绪目标**：读者读完应留下的**一种**具体感觉
   - 确定方法：找"让自己咯噔一下的点" → 找事件自带的反差（表层 vs 底下） → 列 3 个候选情绪用新鲜度/可拍性/主题筛
   - 检验标准：能翻译成一个具体动作才算定准（"熟练得让人心疼" → 逃命后先啃饼）
   - 铁律：一场戏只有一个主导情绪；情绪目标会反向约束机位与细节取舍

## 第 1 阶段：选机位（POV）

| 参数 | 问题 |
|------|------|
| 机位 | 谁的眼睛在看？ |
| 信息权限 | 她能看到/听到/猜到哪些？ |
| 利益相关 | 她和这事什么关系？ |

通用规则：优先选**信息受限但有态度的旁观者**；需要贴近人物时选贴身机位，但必须加信息管制（如"追兵不许入画，只以声音存在"）。

## 第 2 阶段：分镜表

五段骨架，拆成 5~8 拍：

```
① 打破常态的信号 → ② 升级 → ③ 峰值动作 → ④ 收场 → ⑤ 余味（不收口）
```

每拍标注：内容 / 景别（远·中·特） / 感官通道（视·听·嗅·触）。
感官配给原则：先听觉/嗅觉，视觉留给最贵的时刻。

## 第 3 阶段：实拍——句间组接规则

相邻两句只有四种合法接法：

- **A 因果接**：上句的果 = 下句的因
- **B 视线引导**：上句结尾的元素 = 下句的镜头目标（名词顶针，镜头接力）
- **C 反应接**：动作 → 切到别人的反应
- **D 跳切**：换空间/时间/视角（每场最多一两次）

生成规则：
- 一句一个新信息点
- 未知信息先给感官外壳再给本体（先影子后真人）
- **禁用三类句子**：心理结论词、事件解释、作者总结——只写摄影机和麦克风能录到的东西

## 第 4 阶段：剪辑

1. 删解释句（逐句问：这句摄影机能拍到吗？）
2. 调拍序：最有力的细节挪到 ⑤ 余味位
3. 查接力棒：逐句检查 ABCD 接法，接不上就是断点

## 第 5 阶段：调色

- 峰值用短句（节奏 = 心跳）
- 首尾可用同一感官元素画圆
- 最后一句必须是动作，不是结论

---

## 配套逆向流程：阅读拆片法

读到好段落，做四件事：

1. 逐句标镜头属性（景别 / 感官通道）
2. 逐句标接法（ABCD 哪一种）
3. 标功能（属于五拍的哪一拍）
4. 标"替身"：这句换成抽象说法会是什么样——好句和烂句的差别就在这一列

长篇小说/章节额外加问：**戏的功能是什么**（一场戏 vs 系列第一章，配比完全不同）、信息分几批投放、承重墙是哪句。
