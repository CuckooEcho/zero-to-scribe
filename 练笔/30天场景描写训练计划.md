# 30 天场景描写训练计划（富兰克林法）

> 目标：从"写不出场景"到"结构→文字的重建自动化"。
> 方法：富兰克林仿写法——**拆结构 → 间隔遗忘 → 凭结构重写 → 对照原文 → 总结规律**。
> 原料：纯文本（主矿《解忧杂货店》，见 `资料/`），无影视成本，反馈回路最短。
>
> 每天 30 分钟左右。在 `练笔/场景描写/` 下按天建文件（如 `day01.md`）。
> 每周的规律汇总，值得固化的升格为 `卡片库/技法卡`。

## 富兰克林循环（两天一组）

**Day A（拆）**：选一段 300–800 字的场景，合上书填下面的拆解表——
拆的是**思路和顺序**，不是抄句子。填完至少隔半天再写。

**Day B（写+对）**：只看拆解表重写 300–500 字（不看原文）→ 逐段对照原文 →
总结 3 条差异规律写在文末。对照时按三类差异找：
1. **细节选择**：他写的细节里哪些我漏了/我写的哪些他根本不屑写
2. **顺序**：同一个信息他为什么放在那个位置
3. **语气**：同一句话他的措辞比我省在哪/准在哪

## 场景拆解表（Day A 填）

| 项目 | 内容 |
|------|------|
| 原文位置/字数 | （哪章哪段，多少字） |
| 节拍序列 | （这段有几个节拍，每拍一句话概括，按顺序列） |
| 视角 | （谁的眼睛？内视角/外视角？） |
| 细节清单 | （作者选了哪几个细节，按出现顺序） |
| 句式特征 | （平均句长、长短句节奏、有没有突然的单句成段） |
| 五感分布 | （视觉几处、听觉几处、其他几处） |
| 情绪曲线 | （这段从什么情绪到什么情绪） |

## 三条通用自检（写的时候查）

- [ ] **过滤词清零**：删掉"他看到 / 她听到 / 他感到"——直接给画面和声音
- [ ] **少修饰，多动词**：砍掉形容词和副词，动词不用华丽，能把动作说清楚就行
- [ ] **五感+1**：视觉之外至少用一处其他感官

## 易犯的三个结构性错误（前期实录，引以为戒）

1. **视角**：文字没有摄像机，动笔前先定"用谁的眼睛"（客观叙事 / 选定视角人物 / 分段切换）
2. **预支反应**：动作必须等它的原因到场。视线是资源，先给"关注"，后面才有"回避"
3. **时间形态**：先判断这事是"刚发生"（写反应）还是"一直在发生"（写凝固）
