# 第4课完整教案：逻辑推演链的写法

> **精读作品**：有栖川有栖《双头恶魔》（1992）/ 法月纶太郎《近代犯罪史》系列选篇
> **所属流派**：本格推理（逻辑流的巅峰）
> **课时**：4学时（180分钟）
> **前置课程**：第1-3课（已掌握结构、密室、不在场证明）

---

## 一、课程目标

### 知识目标
1. 理解"逻辑推演链"的严格定义与结构（前提→命题→结论）
2. 掌握"挑战读者"模式的设计原理
3. 理解"逻辑与情感的张力"（法月纶太郎的独特贡献）

### 能力目标
1. 能为一个谜题构建完整的逻辑推演链（至少5步）
2. 能写一段"挑战读者"式的文本（在解答前暂停，邀请读者推理）
3. 能识别和修正逻辑链中的"跳跃"（missing link）

### 情感目标
1. 体会纯粹逻辑的"美感"——推理不仅是技术，也是艺术
2. 理解"逻辑正确但情感难以接受"的复杂体验

- **选读**：法月纶太郎《近代犯罪史》系列中的1个短篇
- **复习**：回顾第1-3课的笔记

> **作业1：线索清单**
>
> 读完《双头恶魔》至"挑战读者"页后，列出所有你认为重要的线索（至少10条），标注每条线索的：
> - 类型（物理/证言/行为/元线索）
> - 出现位置（章节/页码）
> - 你认为它指向什么

> **作业2：你的推理**
>
> 在"挑战读者"处停止后，写下你的推理：
> 1. 凶手是谁？（如果你不确定，列出你的前3个怀疑对象及理由）
> 2. 核心诡计是什么？（简述你的猜测）
> 3. 你推理的依据是什么？（列出你依赖的关键线索）
> 4. 你还在困惑什么？（列出尚未解释的现象）

> **作业3：逻辑敏感度测试**
>
> 以下推理是否有逻辑跳跃？如果有，跳跃在哪里？
>
> "A被发现死在书房里，门从内部锁着。B有钥匙，但B声称案发时在外地。监控显示B确实在外地。因此B不是凶手。"

## 三、课前阅读指引（发给学生）

### 《双头恶魔》怎么读？

**第4课是本格推理的"核心语法课"。**

如果说第1课教你搭骨架，第2课教你装门，第3课教你接水管，那么第4课就是教你**让整栋房子通电**——逻辑推演链是推理小说的"电流"，没有它，再好的骨架也只是空壳。

#### 阅读方法："挑战读者"模式

有栖川有栖继承了埃勒里·奎因的"挑战读者"传统：在解答之前，作者会明确告诉读者"所有的线索都已经展示完毕，现在请你推理"。

**这是推理小说最公平的形态。**

**阅读指令**：
1. 读到"挑战读者"页时，**立即停止**
2. 合上书，拿出纸笔
3. 尝试独立解答
4. 写下你的推理过程（不是只写答案，要写"你是怎么得出答案的"）
5. 然后再继续读解答，对比你的推理与侦探的推理

#### 带着这些问题读

1. **"为什么"问题**：每当侦探得出一个结论时，问自己"为什么他能得出这个结论？依据是什么？"
2. **"还有呢"问题**：每当发现一条线索时，问自己"这条线索还有什么可能的解释？"
3. **"如果否"问题**：每当侦探排除一个假说时，问自己"如果这个是假说不成立，那意味着什么？"

#### 读完（至"挑战读者"）之后做一件事

画出"你的逻辑推演链"：
```
线索A → （你的推理）→ 结论1
                    ↓
线索B → （你的推理）→ 结论2
                    ↓
           最终结论：凶手是___，因为___
```

不需要正确，关键是"让逻辑可见"。

## 四、课堂流程（4学时，180分钟）

---

### 第1学时（45分钟）：逻辑推演链的定义与结构

#### 4.1 课程导入：从"零件"到"机器"（10分钟）

**教师开场**：
> "前三课我们学了结构、密室、不在场证明——这些都是'零件'。"
>
> "今天我们要学习的是'组装机器'——逻辑推演链。"
>
> "什么是逻辑推演链？它是从线索到结论的'路径'。没有路径，线索只是散落的珠子；有了路径，珠子就变成项链。"
>
> "有栖川有栖是日本'逻辑流'的代表作家。他的小说以'严谨到偏执'的逻辑著称。读他的作品，你会感到作者在说：'我没有骗你，每一步你都可以验证。'"

**板书**：
```
第4课：逻辑推演链的写法
作者：有栖川有栖（1959- ）
作品：《双头恶魔》（1992）
地位：日本新本格"逻辑流"的巅峰之作
侦探：火村英生（犯罪学者）

辅助参考：法月纶太郎（1964- ）
作品：《近代犯罪史》系列
特色：逻辑推演 + 情感张力
```

#### 4.2 逻辑推演链的定义（15分钟）

**教师讲解**：
> "逻辑推演链不是'我觉得'，不是'可能是'，而是'因为A，所以B；因为B，所以C'。"

**板书：逻辑推演链的结构**
```
逻辑推演链 = 前提（线索）+ 推理规则 + 命题（结论）

标准形式：
前提1：观察到现象A
前提2：已知规律"如果A则B"
─────────────────────────
结论1：B成立

前提3：观察到现象C
前提4：已知规律"B且C则D"
─────────────────────────
结论2：D成立

……（继续推导）

最终结论：凶手是X
```

**逻辑链的"可验证性"原则**：
> "每一步推理都必须满足：一个理智的读者，在知道前提的情况下，可以独立复现这一步推理。"

**反面示例：逻辑跳跃**
```
错误示范：
"死者手上有墨水痕迹。→ 凶手是作家。"

问题：跳跃太大。
手上有墨水 ≠ 是作家（可能是学生、会计、任何人）
手上有墨水 ≠ 凶手（死者自己也可能有墨水）

正确示范：
"死者手上有蓝色墨水痕迹。
+ 现场的信是用蓝色墨水写的。
+ 信上的字迹与死者的日常字迹不同。
+ 信的内容是遗书，但措辞不像死者的习惯。
───────────────────────────────────
→ 遗书可能是伪造的。
→ 伪造者需要接触蓝色墨水。
→ 死者手上的墨水痕迹可能是伪造者留下的。
→ 检查谁的身上有蓝色墨水……"
```

#### 4.3 奎因的遗产："挑战读者"模式（15分钟）

**教师讲解**：
> "有栖川有栖的'挑战读者'不是他自己发明的，而是继承了埃勒里·奎因的传统。"

**板书："挑战读者"模式的原理**
```
"挑战读者" = 作者与读者的"决斗宣言"

流程：
1. 谜面建立（完整）
2. 线索展示（完整）
3. 【挑战读者】← 暂停
   "现在，所有的线索都已经展示给你了。
    在你翻到下一页之前，试着回答：
    凶手是谁？他是如何做到的？"
4. 解答揭晓

功能：
- 对作者：强迫自己在解答前不遗漏任何线索
- 对读者：提供智力对抗的快感
- 对作品：建立"公平性"的最高标准
```

**讨论问题**：
1. 如果一本书没有"挑战读者"，它是否就不公平？
2. 为什么大多数推理小说作家不使用"挑战读者"？（难度太高——作者必须在解答前展示所有线索，且逻辑必须足够严密，否则会被读者"抓包"）
3. "挑战读者"对写作有什么实际影响？（它迫使作者提前规划好整个逻辑链，不能边写边想）

### 第2学时（45分钟）：《双头恶魔》逻辑链拆解

#### 4.4 "挑战读者"前的逻辑盘点（15分钟）

**教师引导**：
> "现在请大家拿出课前作业——你们的'线索清单'和'推理过程'。"
>
> "我们要做一件很有趣的事：看看全班有多少种不同的推理路径。"

**学生活动：推理路径分享**

**教师记录学生推理路径于黑板**：
```
学生A的推理：线索X → 凶手是A
学生B的推理：线索Y → 凶手是B
学生C的推理：线索X+Y → 凶手是C
……
```

**讨论**：
1. 哪些推理路径是"合理的"（即使最终答案不同）？
2. 哪些推理路径存在"逻辑跳跃"？
3. 有没有人被同一条线索误导了？这条线索的"误导力"来自哪里？

#### 4.5 解答篇的逻辑链重建（20分钟）

**教师引导**：
> "现在请大家继续阅读解答篇。我们要做的不是'看答案'，而是'画路径'——把侦探的每一步推理都画出来。"

**学生活动：填写"逻辑推演链 worksheet"**

** worksheet 模板**：
```
《双头恶魔》逻辑推演链重建

步骤1
前提：________________________________________
推理规则：_____________________________________
结论：________________________________________
这个结论排除了什么可能性？_____________________

步骤2
前提：________________________________________
（新线索？还是步骤1的结论？）
推理规则：_____________________________________
结论：________________________________________

步骤3
前提：________________________________________
推理规则：_____________________________________
结论：________________________________________

……

步骤N（最终结论）
前提：________________________________________
推理规则：_____________________________________
结论：凶手是___，手法是___

自我检验：
□ 每一步推理都依赖了前文的前提
□ 没有一步是"显而易见"但不解释的
□ 最终结论解释了所有谜面现象
□ 没有遗漏任何已展示的线索
```

**学生填写 worksheet（10分钟）**

**全班核对（10分钟）**：
- 侦探的逻辑链有多少步？（通常5-10步）
- 哪一步是最关键的"突破口"？
- 你的推理链和侦探的推理链，在哪一步分叉了？为什么？

#### 4.6 法月纶太郎：逻辑与情感的张力（10分钟）

**教师讲解**：
> "有栖川有栖代表'纯逻辑'，法月纶太郎代表'逻辑+情感'。"
>
> "法月的独特之处在于：他的逻辑推演链不仅是'找到真相'，还是'面对真相的艰难'。"

**对比：有栖川有栖 vs 法月纶太郎**

| 对比项 | 有栖川有栖 | 法月纶太郎 |
|--------|-----------|-----------|
| 侦探 | 火村英生（犯罪学者） | 法月纶太郎（同名侦探，贵族后裔） |
| 风格 | 冷静、理性、旁观者视角 | 卷入式、情感化、参与者视角 |
| 逻辑链 | 纯粹的形式逻辑 | 逻辑 + 伦理判断 |
| 解答后 | 案件结束，逻辑闭合 | 案件结束，情感余韵 |
| 核心问题 | "谁是凶手？" | "为什么是这个人？" |

**教学要点**：
> "法月纶太郎证明：逻辑推演链可以承载情感重量。"
>
> "当你设计逻辑链时，不仅要问'这个推理是否严密'，还要问'这个推理是否让人心痛'。"

### 第3学时（45分钟）：逻辑链的写作技法

#### 4.7 "已知信息清单"法（15分钟）

**教师讲解**：
> "写逻辑推演链之前，必须先做一件事：列出'已知信息清单'。"
>
> "这是防止逻辑跳跃的最有效工具。"

**板书：已知信息清单模板**
```
已知信息清单（解答篇写作前必须完成）

编号 │ 信息内容           │ 来源      │ 类型      │ 当前状态
─────┼───────────────────┼─────────┼─────────┼─────────
01  │                    │ 第X章   │ 物理    │ 已展示
02  │                    │ 第X章   │ 证言    │ 已展示
03  │                    │ 第X章   │ 行为    │ 已展示
…… │                    │         │         │

状态说明：
- 已展示：读者和侦探都已看到
- 已展示但隐藏：读者看到了，但没有意识到重要性
- 未展示：只有侦探知道（违反公平性，必须消除）
```

**关键原则**：
> "解答篇中的每一步推理，都必须能从'已知信息清单'中找到依据。"
> "如果某一步推理依赖了一条不在清单上的信息，那就是逻辑跳跃。"

#### 4.8 "假说的墓碑"与"逻辑树"（15分钟）

**教师讲解**：
> "第2课我们学了'假说的墓碑法'——每个被否定的假说都要有明确的否定理由。"
>
> "今天我们要把它升级为'逻辑树'。"

**板书：逻辑树**
```
                    谜面
                     │
        ┌────────────┼────────────┐
        │            │            │
     假说A        假说B        假说C
        │            │            │
   线索1否定    线索2否定    线索3支持
        │            │            │
       死亡        死亡        ┌───┴───┐
                                │       │
                             子假说C1  子假说C2
                                │       │
                           线索4否定  线索5支持
                                        │
                                       存活
                                        │
                                       继续验证……
```

**教学要点**：
> "逻辑树的功能是：让你'看见'所有可能性，确保没有遗漏。"
> "当你画出逻辑树后，你会发现：很多你以为是'灵感'的东西，其实只是'穷举'的结果。"

#### 4.9 课堂练习：逻辑链填空（15分钟）

**练习题目**：

> **案件**：
> A被发现死在家中客厅。门窗完好，无明显搏斗痕迹。死者死于氰化物中毒。
>
> **已知线索**（按出现顺序）：
> 1. 现场有一杯喝了一半的咖啡，经检验含氰化物
> 2. 死者习惯每天下午3点喝咖啡
> 3. 死者秘书B每天下午2:50为死者准备咖啡
> 4. 案发当天，B下午2:30请假提前离开（声称母亲生病）
> 5. B的母亲确实生病了（有医院记录）
> 6. 咖啡杯上只有死者的指纹
> 7. 厨房的糖罐中发现氰化物残留
> 8. 糖罐上的指纹被擦拭过
> 9. 死者昨天与商业对手C发生过激烈争吵
> 10. C案发时在公司开会（有5人作证）
>
> **任务**：
> 用已知信息，补全以下逻辑链。每一步必须说明依据的线索编号。
>
> 步骤1
> 前提：线索___ + 线索___
> 推理：因为________，所以________
> 结论：________________________
>
> 步骤2
> 前提：步骤1的结论 + 线索___
> 推理：因为________，所以________
> 结论：________________________
>
> 步骤3
> 前提：步骤2的结论 + 线索___
> 推理：因为________，所以________
> 结论：________________________
>
> 步骤4
> 前提：步骤3的结论 + 线索___
> 推理：因为________，所以________
> 结论：凶手是___
>
> 检查：是否还有未解释的线索？________________

**学生填写（10分钟）**

**全班讨论（5分钟）**：
- 哪一步是最关键的突破口？
- 线索9（与C的争吵）是红鲱鱼还是真线索？
- 如果这是一个真实案件，还需要什么额外信息？

### 第4学时（45分钟）：综合练习与"挑战读者"仿写

#### 4.10 "挑战读者"仿写（20分钟）

**练习题目**：

> **任务**：写一个1500字的推理场景（谜面+调查），在结尾处加入"挑战读者"段落。
>
> **具体要求**：
>
> **第一部分：谜面（400字）**
> - 建立一个具体的异常现象（不一定是谋杀，可以是盗窃、失踪、奇怪的行为）
> - 至少包含2个需要解释的"为什么"
>
> **第二部分：调查（800字）**
> - 引入一个调查者
> - 展示至少5条线索（物理/证言/行为均可）
> - 调查者提出至少2个假说并否定
> - 不要写解答
>
> **第三部分：挑战读者（300字）**
> - 明确告诉读者"所有线索已经展示完毕"
> - 提出具体问题（至少2个：凶手是谁？/ 如何做到的？/ 动机是什么？）
> - 邀请读者在继续之前尝试解答
> - 语气要有挑战性但友好（不是挑衅，是邀请）
>
> **写作时间**：15分钟

**学生写作（15分钟）**

**互评（5分钟）**：
- 交换作品，检查：是否所有线索都已在"挑战读者"前展示？
- 作为读者，你能否从已展示的线索中推导出至少一种合理的假说？

#### 4.11 逻辑跳跃诊断（15分钟）

**练习题目**：

> **任务**：以下是一段"侦探推理"的草稿。请找出其中的逻辑跳跃，并修正。
>
> "死者死在书房，门从内部锁着。钥匙在死者口袋里。窗户紧闭。书桌上有一杯没喝完的咖啡。侦探注意到咖啡杯底部有一圈水渍，而杯垫是干的。'这说明，'侦探说，'咖啡杯被移动过。死者可能不是在书桌前喝的咖啡，而是被人从别处移过来的。因此，这不是自杀，而是谋杀。凶手把尸体移到书房，制造了密室。'"
>
> **问题**：
> 1. 找出这段话中的所有逻辑跳跃（缺少中间步骤的地方）。
> 2. 为每个跳跃补充缺失的步骤。
> 3. 修正后的推理应该有多少步？

**学生诊断（10分钟）**

**全班核对（5分钟）**：
- 原始推理有多少步？（表面3步：水渍→杯被移动→谋杀）
- 实际应该有多少步？（至少6-7步）
- 最容易被忽视的跳跃是哪一步？

#### 4.12 本课技法总结（10分钟）

**板书：从第4课学到的3个核心技法**

```
技法1：已知信息清单法
┌──────────────────────────────────────────────┐
│ 写解答篇之前，必须先列出所有已知信息。        │
│ 每一步推理都必须能从清单中找到依据。          │
│                                              │
│ 清单格式：                                    │
│ 编号 │ 信息 │ 来源 │ 类型 │ 状态            │
│                                              │
│ 关键检查：                                    │
│ □ 所有解答必需的线索都已展示                  │
│ □ 没有"未展示的信息"被偷偷使用               │
│ □ 红鲱鱼在清单中明确标注                      │
└──────────────────────────────────────────────┘

技法2：逻辑树的穷举法
┌──────────────────────────────────────────────┐
│ 不要依赖"灵感"，要依赖"穷举"。                │
│                                              │
│ 步骤：                                        │
│ 1. 列出谜面的所有可能解释（至少3个）          │
│ 2. 用线索逐一检验每个解释                     │
│ 3. 被否定的解释要有"墓碑"（明确否定理由）     │
│ 4. 存活的解释继续细分（子假说）               │
│ 5. 直到只剩下唯一一个解释                     │
│                                              │
│ 效果：读者感到"所有可能性都被考虑到了"        │
└──────────────────────────────────────────────┘

技法3："挑战读者"模式
┌──────────────────────────────────────────────┐
│ 在解答前明确暂停，邀请读者推理。              │
│                                              │
│ 写作要点：                                    │
│ 1. 暂停的时机：所有线索已展示，侦探即将推理   │
│ 2. 问题的设计：具体、可回答、不开放           │
│    （不要问"发生了什么"，要问"凶手是谁"）    │
│ 3. 语气：挑战但友好，自信但不傲慢             │
│                                              │
│ 效果：                                        │
│ - 强迫作者自己检查公平性                      │
│ - 给读者智力对抗的快感                        │
│ - 建立作品的"经典感"                         │
└──────────────────────────────────────────────┘
```

## 五、课后作业

### 作业1：逻辑链完善（必做）

> 修改课堂练习中的"逻辑链填空"，为每一步补充更详细的推理规则。
> 例如，不要只写"因为咖啡有毒，所以秘书可疑"，要写：
> "因为死者每天下午3点喝咖啡（习惯），而秘书每天2:50准备咖啡（职责），
> 所以秘书有机会在咖啡中下毒（机会）。
> 但机会≠动机，需要进一步调查秘书的动机……"
>
> 目标：让每一步都"无跳跃"。

### 作业2："挑战读者"完整版（必做）

> 把课堂练习中的"挑战读者仿写"扩展为完整短篇（2000字以内），加入解答篇。
> 要求：
> - 解答必须严格依赖"挑战读者"前展示的线索
> - 解答的逻辑链至少5步
> - 附："已知信息清单"（至少8条）

### 作业3：逻辑敏感度训练（日常）

> 本周任选一天，观察身边的3个"异常"（例如：某人今天比平时早到、某物的位置变了、某人的态度不同了）。
> 为每个异常写一段"侦探式推理"：
> - 异常是什么？
> - 可能的解释有哪些？（至少2个）
> - 哪个解释最合理？依据是什么？
>
> 这不需要正确，只需要训练"把日常变成逻辑推演"的习惯。

## 七、教师备查资料

### 7.1 《双头恶魔》详细拆解（教师参考）

**基本信息**：
- 首次发表：1992年
- 中译本字数：约10万字（长篇）
- 类型：本格推理（逻辑流）
- 侦探：火村英生（犯罪学者）+ 有栖川有栖（叙述者/助手）

**核心特点**：
- 严格的"挑战读者"模式
- 多重线索交织，逻辑链长而严密
- 火村英生的"安乐椅神探"模式（常在沙发上推理）

**与埃勒里·奎因的对比**：
| 对比项 | 埃勒里·奎因 | 有栖川有栖 |
|--------|-----------|-----------|
| 侦探 | 埃勒里·奎因（纽约警探之子） | 火村英生（京都大学犯罪学者） |
| 助手 | 奎因警官（父亲） | 有栖川有栖（作家本人，叙述者） |
| 风格 | 美国都市、快节奏 | 日本学院、慢节奏 |
| 逻辑链 | 直接、简洁 | 复杂、多层次 |
| "挑战读者" | 每一部都有 | 部分作品有 |

### 7.2 常见学生问题与应对

| 学生问题 | 教师应对 |
|---------|---------|
| "我的逻辑链太长了，读者会失去耐心。" | 回应：逻辑链的长度不是问题，问题是"节奏"。你可以把长逻辑链分成几段，每段之间有"小结论"作为休息站。 |
| "我觉得'挑战读者'很做作，不想用。" | 回应："挑战读者"是一种可选技法，不是必须的。但它的核心价值是"强迫你自己检查公平性"。即使不在书中写出来，写作时也应该在心里对自己"挑战"。 |
| "法月纶太郎的'情感'部分怎么学？" | 回应：先学好纯逻辑（有栖川有栖），再学逻辑+情感（法月纶太郎）。情感不是外加的，而是逻辑推导的"副作用"——当你发现真相指向一个你同情的人时，情感就自然产生了。 |
| "我的推理总是被同学一眼看穿。" | 回应：那说明你的"误导"不够。 revisit 第2课的"红鲱鱼"技法和第3课的"过度证明"技法。逻辑链的严密性和诡计的隐蔽性是两回事。 |

### 7.3 课堂时间备用方案

如果学生阅读速度快，第3-4学时可以增加：
- **"逻辑链接力"**：分组竞赛，每组写一步推理，下一组必须在前一组的基础上继续，不能跳跃。看哪组的逻辑链最长且最严密。
- **"反逻辑练习"**：给定一个结论，让学生倒推设计逻辑链——从"凶手是X"出发，倒推需要哪些前提和推理步骤。
