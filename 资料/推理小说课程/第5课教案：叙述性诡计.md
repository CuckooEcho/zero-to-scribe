# 第5课完整教案：叙述性诡计

> **精读作品**：我孙子武丸《杀戮之病》（1992）/ 东野圭吾《恶意》（1996，倒叙视角补充）
> **所属流派**：本格推理（叙述性诡计是日本的独门武器）
> **课时**：4学时（180分钟）
> **前置课程**：第1-4课（已掌握结构、密室、不在场证明、逻辑链）
> **内容提示**：《杀戮之病》涉及极端犯罪描写，教学中侧重"技法拆解"而非"内容复述"

---

## 一、课程目标

### 知识目标
1. 理解"叙述性诡计"的严格定义与运作原理（语言的能指与所指的间隙）
2. 掌握叙述性诡计的四大类型（身份/数量/性别/物理形态）
3. 理解叙述性诡计的"公平性边界"——事后可验证原则

### 能力目标
1. 能写出一段"中性化叙述"（隐藏叙述者关键信息，但文本语法无谎言）
2. 能在一篇文本中预埋至少3条"事后可见"的线索
3. 能区分"合理的叙述性诡计"与"欺骗性叙述"

### 情感目标
1. 理解叙述性诡计对"读者信任"的颠覆——重新审视"第一人称"
2. 体会"重读"的乐趣——知道真相后，文本会呈现全新的意义

### 学生课前任务

#### 阅读任务
- **必读**：《杀戮之病》全文
- **选读**：东野圭吾《恶意》前半部分（至凶手身份揭露）
- **特别准备**：2支不同颜色的笔（第一遍阅读用黑色，第二遍用红色）

#### 课前作业（书面，课前交）

> **作业1：第一遍阅读笔记**
>
> 用黑色笔读完《杀戮之病》第一遍，记录：
> 1. 你对"叙述者"的印象：性别、年龄、职业、与案件的关系
> 2. 叙述者什么时候出场？以什么身份出场？
> 3. 叙述者描述自己的方式有什么特点？（例如：是否提到外貌？是否使用镜子？）
> 4. 叙述者与其他角色的互动方式有什么特点？

> **作业2：第二遍重读标记**
>
> 知道真相后，用红色笔重读前半部分，标记所有"事后看来可疑"的描述。
> 列出至少5条"事后线索"，说明：
> - 这条描述在第一遍阅读时给你的印象是什么？
> - 知道真相后，这条描述的含义变成了什么？

> **作业3：《恶意》对比**
>
> 《恶意》也使用了特殊的叙述视角（倒叙+凶手自白）。
> 对比《杀戮之病》和《恶意》：两者的"叙述诡计"有什么不同？
> （提示：《恶意》的诡计是"时间顺序"，不是"叙述者身份"。）

## 三、课前阅读指引（发给学生）

### 《杀戮之病》怎么读？

**第5课是"信任崩塌"的一课。**

读完这本书后，你将永远无法以同样的方式读任何一本第一人称小说。这是叙述性诡计的"诅咒"——也是它的魅力。

#### 阅读方法：双笔阅读法

**第一遍（黑色笔）**：正常阅读，不要猜测叙述者身份。相信叙述者。沉浸故事。

**第二遍（红色笔）**：知道真相后重读。这次你是一个"侦探"，任务是"审问文本"——每一句话都不放过，检查是否有"语法上的真实但语义上的误导"。

#### 带着这些问题读

1. **"我"的问题**：叙述者在什么情况下使用"我"？在什么情况下省略主语？这种选择是否有规律？
2. **"镜子"问题**：叙述者是否描述过自己的外貌？是否照过镜子？是否被他人描述过外貌？
3. **"身体"问题**：叙述者是否提到自己的身体感受？（疼痛、疲劳、饥饿、冷热）这些感受有什么特点？
4. **"人称"问题**：叙述者如何称呼其他角色？（名字？关系？代词？）其他角色如何称呼叙述者？
5. **"视角盲区"问题**：叙述者"看不到"什么？（是物理上看不到，还是选择不描述？）

#### 读完之后做一件事

**写一封"给叙述者的信"**：
> 以读者的身份，给这本书的叙述者写一封信（200字）。
> 第一遍读完写一封（表达你的信任或同情）。
> 第二遍读完再写一封（表达你的被背叛感或恍然大悟）。
> 对比两封信，感受"叙述"如何操控"理解"。

### 第1学时（45分钟）：叙述性诡计的定义与原理

#### 4.1 课程导入：信任的崩塌（10分钟）

**教师开场**：
> "前四课我们学了推理小说的'硬件'——结构、密室、不在场证明、逻辑链。"
>
> "今天我们要学的是'软件'——叙述。"
>
> "更准确地说，我们要学的是：作者如何通过操控叙述，让读者'自己骗自己'。"
>
> "我孙子武丸的《杀戮之病》是叙述性诡计的极端案例。我不想过多复述它的内容——你们已经读过了。我们今天要拆解的是：它是怎么做到的？"

**板书**：
```
第5课：叙述性诡计
作者：我孙子武丸（1957- ）
作品：《杀戮之病》（1992）
地位：叙述性诡计的极端典范（内容争议大，技法价值高）

辅助参考：东野圭吾《恶意》（1996）
特色：倒叙叙述视角，时间顺序作为诡计
```

#### 4.2 叙述性诡计的定义（15分钟）

**教师讲解**：
> "什么是叙述性诡计？"
>
> "定义：作者利用叙事语言的模糊性，使读者对叙述者的身份、数量、性别、年龄或物理形态形成错误认知，而文本本身在语法层面并无谎言。"

**板书：叙述性诡计的核心原理**
```
语言的"能指-所指"间隙

能指（文字符号） ──→ 所指（读者理解的意义）
     │                        │
     │      间隙（认知偏差）    │
     │                        │
   "我"              读者以为的"我"
   （语法上真实的      （可能是错误的
    第一人称）         身份假设）

叙述性诡计 = 利用这个间隙
```

**关键原则**：
> "叙述性诡计不是'作者在撒谎'，而是'读者在误解'。"
> "文本本身在语法上是完全真实的——每一个字都是真的，只是读者把真的东西理解错了。"

**叙述性诡计的四大类型**：

| 类型 | 核心原理 | 经典案例 | 操作难度 |
|------|---------|---------|---------|
| **身份隐藏** | 叙述者就是凶手/关键人物 | 《罗杰疑案》《杀戮之病》 | ⭐⭐⭐ |
| **数量隐藏** | 多个叙述者实为同一人，或反之 | 《倒错的轮舞曲》 | ⭐⭐⭐⭐ |
| **性别/年龄隐藏** | 利用语言的中性特征 | 某经典作品 | ⭐⭐ |
| **物理形态隐藏** | 叙述者不是人类/不是读者以为的形态 | 《樱树抽芽时，想你》 | ⭐⭐⭐⭐⭐ |

#### 4.3 事后可验证原则（15分钟）

**教师讲解**：
> "叙述性诡计最大的争议是'公平性'。"
>
> "如果作者完全隐藏叙述者的身份，没有任何线索，那这不是推理，是欺骗。"
>
> "因此，叙述性诡计必须满足'事后可验证'原则。"

**板书：事后可验证原则**
```
事后可验证原则 = 知道真相后，重读前文
                  能发现至少3-5条明确的暗示线索

这些线索必须满足：
1. 语法上真实（不是谎言）
2. 语义上双关（可以有两种解读）
3. 第一遍阅读时合理（不会引起怀疑）
4. 第二遍阅读时明显（会引人注意）
```

**《杀戮之病》的事后线索示例**（教师根据课堂氛围选择性展示）：

| 线索 | 第一遍阅读的印象 | 第二遍阅读的含义 |
|------|----------------|----------------|
| 叙述者从不描述自己的身体 | "作者没写而已" | "因为身体特征会暴露身份" |
| 叙述者对某些场景有异常详细的记忆 | "记忆力好" | "因为这是叙述者亲历的" |
| 叙述者对某些话题有异常强烈的反应 | "性格敏感" | "因为与叙述者的真实身份相关" |

**讨论问题**：
1. 如果一条线索在事后仍然"不明显"，这是否违反公平性？
2. "事后可验证"和"事前可推导"之间有多大差距？（理想情况是：事前可推导；可接受情况是：事后可验证；不可接受情况是：事后仍然模糊）

### 第2学时（45分钟）：《杀戮之病》深度拆解

#### 4.4 叙述者的"隐身术"（15分钟）

**教师引导**：
> "现在我们来拆解《杀戮之病》的'隐身术'——作者是如何让叙述者'隐形'的。"

**板书：叙述者隐身的技术**
```
技术1：信息控制
- 叙述者主动选择"不描述"某些信息
- 例如：不照镜子、不拍照、不被人描述外貌
- 效果：读者无法获得叙述者的物理特征

技术2：视角限制
- 叙述者只描述"看到的"，不描述"自己"
- 例如："他走向我"而不是"他走向那个穿红衣服的我"
- 效果：叙述者像一个"漂浮的视角"

技术3：情感引导
- 叙述者描述强烈的情感，转移读者的注意力
- 例如：详细描写恐惧、愤怒、同情
- 效果：读者沉浸在情感中，忽略了"谁在感受这些情感"

技术4：语言中性化
- 避免使用性别代词指代自己
- 避免描述与年龄相关的特征
- 效果：读者的默认假设被维持
```

**关键洞察**：
> "叙述性诡计的成功，不取决于'作者隐藏了什么'，而取决于'读者默认了什么'。"
> "读者之所以被骗，不是因为他们笨，而是因为他们太习惯于某种叙述模式。"

#### 4.5 "中性化语言"的写作技术（15分钟）

**教师讲解**：
> "如果你想写叙述性诡计，你必须学会'中性化语言'。"

**板书：中性化语言的技术**
```
需要避免的（会暴露身份）：
❌ "我穿上裙子" → 暴露性别
❌ "我摸了摸胡子" → 暴露性别+年龄
❌ "我弯下腰，因为背痛" → 暴露年龄
❌ "孩子们叫我阿姨" → 暴露性别+年龄
❌ "我照镜子，整理领带" → 暴露外貌细节

可以使用的（中性化）：
✅ "我拿起包，走出房间"
✅ "有人在叫我，我转过身"
✅ "我感到累，坐在椅子上"
✅ "他看着我，我看着他"
✅ "雨开始下了，我站在屋檐下"
```

**中性化的核心策略**：
1. **动作代替外貌**：写"我做了什么"，不写"我长什么样"
2. **关系代替身份**：写"我是他的朋友"，不写"我是他的同事/老师/医生"
3. **感受代替特征**：写"我感到紧张"，不写"我的手在抖"
4. **环境代替身体**：写"房间很暗"，不写"我看不清"

#### 4.6 东野圭吾《恶意》的对比（15分钟）

**教师讲解**：
> "《杀戮之病》是'身份隐藏型'叙述性诡计。东野圭吾的《恶意》是另一种——'时间顺序型'。"

**板书：《恶意》的叙述诡计**
```
《恶意》的诡计：时间顺序的误导

表面：
第一章 → 凶手被抓 → 凶手自白 → 侦探调查 → 真相
（顺叙：凶手→动机→真相）

实际：
凶手自白中隐藏了"时间错位"
某些事件的发生顺序被叙述者重新排列
读者的"因果理解"被误导

关键差异：
- 《杀戮之病》："我是谁"被误导
- 《恶意》："什么时候发生了什么"被误导
```

**教学要点**：
> "《恶意》比《杀戮之病》更适合新手学习，因为它的'公平性'更高。"
> "《恶意》的所有线索在事后都'非常明显'——你只要重新排列时间顺序，真相就浮出水面。"
> "而《杀戮之病》的线索更隐蔽，需要更细致的文本分析。"

### 第3学时（45分钟）：叙述性诡计的写作技法

#### 4.7 "事后线索"的设计（15分钟）

**教师讲解**：
> "写叙述性诡计最难的部分：设计'事后线索'。"
>
> "这些线索必须同时满足两个矛盾的要求："
> "1. 第一次阅读时：不引人注意"
> "2. 第二次阅读时：非常明显"

**板书：事后线索的设计原则**
```
事后线索的"三层效果"：

第一层（第一次阅读）：
→ "哦，这是一个普通的细节。"
→ 功能：建立默认假设

第二层（解答揭晓时）：
→ "等等，那个细节是不是有问题？"
→ 功能：制造"啊！"的瞬间

第三层（第二次阅读）：
→ "原来如此！作者早就告诉我了！"
→ 功能：提供重读的乐趣
```

**事后线索的常见类型**：

| 类型 | 示例 | 效果 |
|------|------|------|
| 缺席线索 | 叙述者从不提及自己的身体 | "缺席"本身成为线索 |
| 反应线索 | 叙述者对某些话题反应过度 | 反应的强度暴露身份 |
| 称谓线索 | 其他角色对叙述者的称呼有微妙异常 | 称谓暗示真实关系 |
| 知识线索 | 叙述者知道不该知道的事 | 知识范围暴露身份 |
| 语言线索 | 叙述者使用的词汇/句式有特征 | 语言习惯暴露背景 |

#### 4.8 课堂练习：中性叙述仿写（15分钟）

**练习题目**：

> **任务**：用400字写一段第一人称叙述，描写"我"目睹一场街头争吵。
>
> **要求**：
> 1. 全文不出现"我"的性别、年龄、外貌、职业
> 2. 全文不使用"他"或"她"指代叙述者自己
> 3. 但叙述者的身份必须通过"其他角色的反应"暗示出来
>    （例如：如果叙述者是警察，路人可能对叙述者说"警官，这里"；
>     如果叙述者是小孩，大人可能对叙述者说"小朋友，让开"）
> 4. 写完后，让同学猜测叙述者的身份
>
> **写作时间**：10分钟

**学生写作（10分钟）**

**互猜（5分钟）**：
- 交换作品，猜测叙述者的身份
- 如果猜对了：说明作者的暗示足够明显
- 如果猜错了：说明作者的暗示太隐晦，或者误导太成功
- 讨论：哪些暗示"有效"？哪些"太明显"或"太隐蔽"？

#### 4.9 课堂练习：事后线索设计（15分钟）

**练习题目**：

> **任务**：设计一个叙述性诡计的"线索清单"。
>
> **设定**：叙述者是一个你选择的"隐藏身份"（例如：凶手、小孩、老人、非人类）。
>
> **要求**：
> 1. 确定叙述者的真实身份
> 2. 列出至少5条"事后线索"，每条满足：
>    - 第一遍阅读时：合理、不引人注意
>    - 第二遍阅读时：明显、指向真实身份
> 3. 写出每条线索在文本中的"第一遍版本"和"第二遍版本"
>
> **示例格式**：
> 线索1：
> - 第一遍："我走进房间，坐在椅子上。"（普通动作）
> - 第二遍："我走进房间，坐在椅子上。"（注意：叙述者没有'弯腰'的动作——暗示叙述者身高与椅子高度匹配，可能是小孩？）

**学生设计（10分钟）**

**分享（5分钟）**：
- 选择2-3组分享他们的线索设计
- 全班评估：哪条线索最巧妙？（既隐蔽又明显）

### 第4学时（45分钟）：叙述性诡计的伦理边界与综合练习

#### 4.10 叙述性诡计的"伦理边界"（10分钟）

**教师引导**：
> "叙述性诡计有一个伦理问题：它是否'公平'？"
>
> "如果读者被误导了，他们是'被骗'还是'被挑战'？"

**讨论**：
1. 《杀戮之病》的叙述性诡计是否公平？为什么？
2. 如果一本书的叙述性诡计事后仍然"找不到线索"，你是否会感到被欺骗？
3. 叙述性诡计的"可接受程度"在哪里？

**板书：叙述性诡计的"光谱"**
```
完全不可接受 ←────────────────→ 完全可接受

1. 纯粹欺骗        4. 事后可验证      7. 事前可推导
   （作者撒谎）       （重读能找到线索）  （细心的读者
   （没有线索）                          能提前猜到）

《杀戮之病》的位置：约5-6（事后可验证，但线索较隐蔽）
《恶意》的位置：约6-7（事后很明显，细心的读者可能提前猜到）
```

#### 4.11 综合练习：叙述性诡计短篇（20分钟）

**练习题目**：

> **任务**：写一个800字的微型叙述性诡计短篇。
>
> **具体要求**：
> **第一部分（500字）：第一人称叙述**
> - 叙述者目睹或参与了一个事件（可以是犯罪、失踪、意外）
> - 叙述者描述自己的观察、感受、推理
> - 叙述者的真实身份被隐藏（但不能违反语法）
> - 预埋至少3条事后线索
>
> **第二部分（300字）：解答**
> - 揭示叙述者的真实身份
> - 解释第一部分中的"异常"如何被重新理解
> - 所有解答必须依赖第一部分已展示的信息
>
> **写作时间**：15分钟

**学生写作（15分钟）**

**互评（5分钟）**：
- 交换作品，先读第一部分，猜测叙述者身份
- 然后读第二部分，检查：
  1. 解答是否依赖第一部分的信息？
  2. 事后线索是否"合理又隐蔽"？
  3. 叙述是否有语法上的谎言？

#### 4.12 本课技法总结（15分钟）

**板书：从第5课学到的3个核心技法**

```
技法1：中性化语言
┌──────────────────────────────────────────────┐
│ 叙述性诡计的核心技术：让文本"语法真实"        │
│ 但"语义双关"。                                │
│                                              │
│ 操作清单：                                    │
│ □ 避免描述叙述者的身体外貌                    │
│ □ 避免使用性别代词指代叙述者                  │
│ □ 避免描述与年龄相关的特征                    │
│ □ 用动作代替外貌，用感受代替特征              │
│ □ 让其他角色的反应暗示叙述者的身份            │
└──────────────────────────────────────────────┘

技法2：事后线索的三层效果
┌──────────────────────────────────────────────┐
│ 第一层：建立默认假设（不引人注意）            │
│ 第二层：制造"啊！"瞬间（解答时恍然大悟）      │
│ 第三层：提供重读乐趣（第二遍发现更多）        │
│                                              │
│ 常见线索类型：                                │
│ - 缺席线索（叙述者从不做的事）                │
│ - 反应线索（对特定话题的过度反应）            │
│ - 称谓线索（其他角色的称呼方式）              │
│ - 知识线索（叙述者知道不该知道的事）          │
└──────────────────────────────────────────────┘

技法3：事后可验证原则
┌──────────────────────────────────────────────┐
│ 叙述性诡计的底线：事后重读时，                │
│ 必须能找到至少3条明确线索。                   │
│                                              │
│ 如果事后仍然找不到线索 → 这是欺骗，不是推理 │
│ 如果事前就能猜到 → 这是失败的叙述性诡计     │
│                                              │
│ 理想状态：5-6分（事后明显，事前隐蔽）         │
└──────────────────────────────────────────────┘
```

## 七、教师备查资料

### 7.1 《杀戮之病》叙述性诡计拆解（教师参考）

**核心诡计类型**：身份隐藏型（叙述者 = 凶手）

**公平性评估**：
- 事后线索：有，但较隐蔽（需要仔细阅读才能发现）
- 位置：光谱约5-6分（事后可验证，但非明显）
- 争议：部分读者认为线索过于隐蔽，接近"欺骗"

**叙述者隐身技术分析**：
1. **视角选择**：第一人称有限视角，只描述"看到的"，不描述"自己"
2. **信息过滤**：叙述者主动省略所有可能暴露身份的身体描述
3. **情感转移**：用强烈的情感描写转移读者对"叙述者是谁"的注意力
4. **语言中性化**：避免使用性别代词、年龄相关词汇

### 7.2 常见学生问题与应对

| 学生问题 | 教师应对 |
|---------|---------|
| "叙述性诡计是不是在作弊？" | 回应：取决于"事后是否有线索"。如果有，这是挑战；如果没有，这是欺骗。我们追求的是"公平的叙述性诡计"。 |
| "我不想写叙述性诡计，感觉太 tricksy 了。" | 回应：完全没问题。叙述性诡计是可选技法，不是必选项。学好本格结构、密室、逻辑链，同样可以写出优秀的推理小说。 |
| "我写的叙述性诡计，同学一眼就猜到了。" | 回应：说明你的暗示太明显。试试"分散注意力"——在隐藏线索的同时，加入一个更吸引人的"假线索"，让读者被假线索吸引。 |
| "《杀戮之病》的内容让我不舒服。" | 回应：理解。这部作品的内容确实极端。如果你感到不适，可以选择不深入讨论内容，只学习其"叙述技术"。《恶意》是更温和的替代教材。 |

### 7.3 课堂时间备用方案

如果学生阅读速度快，第3-4学时可以增加：
- **"叙述者审讯"**：分组扮演"侦探"和"叙述者"，侦探通过提问试图确定叙述者的身份，叙述者只能回答文本中已出现的信息
- **"身份替换练习"**：给定一个场景，让学生分别以"警察""凶手""小孩""老人"的身份叙述同一事件，体会不同身份如何影响叙述方式
