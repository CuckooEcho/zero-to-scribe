# 第7课完整教案：新本格的暴风雪山庄

> **精读作品**：绫辻行人《十角馆事件》（1987）
> **所属流派**：新本格推理（日本推理小说的"第二次革命"）
> **课时**：4学时（180分钟）
> **前置课程**：第1-6课（本格基础模块全部完成）
> **课程定位**：综合运用课——将前6课所学全部技法整合到一个完整的暴风雪山庄框架中

---

## 一、课程目标

### 知识目标
1. 理解"暴风雪山庄"的严格定义与最小模型（三个必要条件）
2. 掌握"死亡预告"（童谣/规律）的叙事功能与设计原则
3. 理解"建筑诡计"的基本类型与运用
4. 理解"新本格"运动的起源与核心主张

### 能力目标
1. 能独立设计一个暴风雪山庄的完整大纲（含6-8人、3-4起死亡、核心诡计）
2. 能写暴风雪山庄的"第一章"（建立人物、隔离状态、第一个异常）
3. 能管理"嫌疑人集合"的逐步缩小（每死一人，更新嫌疑人名单）

### 情感目标
1. 体会"封闭空间中的人性"——恐惧、猜疑、联盟与背叛
2. 理解新本格运动对推理小说边界的拓展

## 三、课前阅读指引（发给学生）

### 《十角馆事件》怎么读？

**第7课是"综合运用课"——把前6课学的所有东西，放进一个"大容器"里。**

暴风雪山庄是推理小说的"终极考场"：它同时考验你的结构能力、密室设计、不在场证明管理、逻辑推演、叙述控制和反转设计。

#### 阅读方法：侦探模式

读《十角馆事件》时，你就是侦探。你的任务是：
1. **记录**：每个人物每天的行动
2. **标记**：每条线索出现的位置
3. **猜测**：每死一个人，更新你的嫌疑人名单
4. **验证**：解答篇揭晓时，检查你的推理有多少正确

#### 带着这些问题读

1. **"隔离"问题**：十角馆是如何被隔离的？这种隔离是"物理的"还是"心理的"？
2. **"建筑"问题**：十角馆的建筑结构有什么特别之处？这种特别之处如何服务于诡计？
3. **"人数"问题**：为什么出场人物是"这个数量"？多一个或少一个会有什么不同？
4. **"死亡顺序"问题**：谁先死？谁后死？死亡顺序是谁决定的？为什么这样安排？
5. **"凶手隐藏"问题**：凶手如何在众人眼皮底下杀人？他/她的"掩护"是什么？

#### 读完之后做一件事

**制作"嫌疑人管理表"**：
```
死亡顺序：死者1 → 死者2 → 死者3 → ……

每死一人，更新存活者名单和嫌疑指数：

第1人死亡后：
存活者：A（嫌疑5）、B（嫌疑7）、C（嫌疑3）……

第2人死亡后：
存活者：A（嫌疑6）、B（嫌疑8）、C（嫌疑2）……

……

最后存活者：___（凶手？还是幸存者？）
```

### 第1学时（45分钟）：新本格运动与暴风雪山庄的定义

#### 4.1 课程导入：推理小说的"第二次革命"（10分钟）

**教师开场**：
> "1980年代，日本推理小说发生了一场'革命'。"
>
> "在此之前，推理小说已经被'社会派'主导了二十多年。松本清张证明：推理小说可以写社会、写人性、写黑暗。"
>
> "但一群年轻作家说：我们想把'推理'重新放回到中心。我们想让诡计更大、更华丽、更不可能。"
>
> "这场运动，就是'新本格'。"
>
> "今天我们要读的《十角馆事件》，是新本格的'开山之作'。它的作者绫辻行人，当时还是一个大学生。"

**板书**：
```
第7课：新本格的暴风雪山庄
作者：绫辻行人（1960- ）
作品：《十角馆事件》（1987）
地位：新本格运动的开山之作

新本格运动背景：
- 1987年，岛田庄司发表《本格推理宣言》
- 核心主张：推理小说应该回归"诡计"和"逻辑"
- 但诡计可以更大胆、更华丽、更突破常规
- 新本格 ≠ 旧本格的复制，而是旧本格的扩展
```

#### 4.2 暴风雪山庄的定义与最小模型（15分钟）

**教师讲解**：
> "暴风雪山庄是推理小说的经典结构。但它不是'有暴风雪的山庄'那么简单。"

**板书：暴风雪山庄的严格定义**
```
暴风雪山庄 = 物理隔离 + 通信中断 + 嫌疑人有限

1. 物理隔离：外部人员无法自由进出
   → 原因：暴风雪、洪水、桥梁断裂、船只沉没、疫情封锁……

2. 通信中断：无法向外界求助或传递信息
   → 原因：电话线断、手机没信号、暴风雨干扰……

3. 嫌疑人有限：凶手必须在已知人员之中
   → 功能：将嫌疑人集合S收缩为有限集合
   → 结果：排除法得以应用

最小模型：
- 不需要宏大的建筑
- 不需要复杂的历史
- 只需要满足上述三个条件
→ 例：一辆抛锚的巴士、一艘失去动力的船、一个被封锁的公寓
```

**暴风雪山庄的"心理效应"**：
```
封闭空间的心理动力学：

初始阶段（0-24小时）：
→ 恐慌 + 互相安慰
→ "只要等到救援就好了"

发展阶段（24-48小时）：
→ 怀疑 + 联盟形成
→ "凶手就在我们之中"

高潮阶段（48小时+）：
→ 偏执 + 互相指责
→ "任何人都可能是凶手"

功能：
封闭空间加速了人性的"极端化"
正常情况下的"礼貌"和"克制"被压力摧毁
→ 为角色行为提供合理性
```

#### 4.3 绫辻行人的"馆系列"与建筑诡计（15分钟）

**教师讲解**：
> "绫辻行人的独特贡献是'建筑诡计'。"
> "在他的'馆系列'中，建筑本身是一个角色——它不仅是背景，还是凶手。"

**板书：馆系列概览**
```
绫辻行人"馆系列"：

《十角馆事件》（1987）——十角馆
《水车馆幻影》（1988）——水车馆
《迷宫馆事件》（1988）——迷宫馆
《人偶馆事件》（1989）——人偶馆
《钟表馆事件》（1991）——钟表馆
《黑猫馆事件》（1992）——黑猫馆
《暗黑馆事件》（2004）——暗黑馆

共同特点：
1. 每部都有一座"特殊建筑"
2. 建筑的结构本身服务于诡计
3. 建筑的名称暗示了诡计的类型
```

**十角馆的建筑特点**：
- 十角形 = 没有"正面"和"背面"
- 每个房间形状相同 = 容易混淆
- 中心大厅 = 所有人的交汇点
- 建筑特点如何服务于诡计？（课堂上根据学生阅读情况揭示）

**教学要点**：
> "建筑诡计的核心是：让读者'默认'建筑是'正常的'，然后揭示建筑的'异常'。"
> "这种'默认'本身就是诡计的一部分。"

### 第2学时（45分钟）：《十角馆事件》综合拆解

#### 4.4 人物管理与死亡顺序（15分钟）

**教师引导**：
> "暴风雪山庄的核心挑战之一是'人物管理'。"
> "每死一个人，故事的动态就变了。"

**板书：人物管理原则**
```
暴风雪山庄的人物管理：

初始状态：
→ 6-10人，每人有表面身份和隐藏秘密
→ 所有人都有"某种"嫌疑（否则读者不会关注他们）
→ 所有人都有"某种"无辜证据（否则太容易被排除）

死亡顺序的设计原则：
1. 早期死亡者：不能是凶手（否则读者会觉得被欺骗）
   → 功能：减少嫌疑人数量、制造恐慌、提供线索

2. 中期死亡者：可以"看似"重要，但实际是"牺牲品"
   → 功能：误导读者、制造"凶手在针对某种类型的人"的假象

3. 晚期存活者：必须是"有嫌疑又有无辜证据"的人
   → 功能：维持悬念到最后

4. 凶手的存活策略：
   → 凶手不能第一个死（否则没有凶手了）
   → 凶手不能最后一个死（太明显）
   → 凶手最好在"中间位置"死亡（假装死亡/伪装受害者）
```

**《十角馆事件》的人物与死亡分析**（根据学生阅读情况揭示）

#### 4.5 童谣/预告的设计（15分钟）

**教师讲解**：
> "《十角馆事件》使用了童谣/预告。这不是绫辻行人的发明——阿加莎·克里斯蒂的《无人生还》才是鼻祖。"
>
> "但绫辻行人证明了：这个技法可以被现代化。"

**板书：童谣/预告的叙事功能**
```
童谣/预告的三重功能：

功能1：制造悬念
→ "下一个是谁？"
→ 读者会主动对比童谣内容和存活者名单
→ 效果：阅读速度加快，紧张感增强

功能2：制造对称感
→ 连续犯罪有了"规律"而非随机
→ 效果：让读者感到"凶手在遵循某种规则"

功能3：为凶手提供掩护
→ 凶手利用童谣的"规律性"来隐藏自己
→ 效果：读者关注"谁会按童谣死去"，忽略了"谁在操控童谣"

设计原则：
1. 预告必须足够模糊——不能让读者直接猜到凶手
2. 预告必须足够具体——让凶手的行为看起来"有规则"
3. 预告必须可被打破——最后的解答应该揭示"凶手只是在假装遵循规则"
```

**《十角馆事件》的童谣分析**（教师引导学生讨论）

### 第3学时（45分钟）：暴风雪山庄的写作技法

#### 4.7 暴风雪山庄的设计流程（20分钟）

**教师讲解**：
> "现在我们来学习如何设计一个暴风雪山庄。"
> "这是前6课所有技法的综合运用。"

**板书：暴风雪山庄设计流程**
```
步骤1：确定隔离方式
├── 自然隔离（暴风雪、洪水、地震）
├── 人为隔离（桥断、船沉、封锁）
└── 混合隔离（自然+人为）
→ 选择原则：与故事主题和氛围匹配

步骤2：设计建筑/空间
├── 建筑类型：古宅、别墅、列车、船、孤岛……
├── 建筑特点：必须有一个"服务于诡计"的结构特征
└── 房间数量：≥出场人物数量

步骤3：设计人物（6-10人）
├── 每人：表面身份 + 隐藏秘密
├── 每人：与其他至少2人有关系
├── 至少2人有"明显的动机"
├── 至少2人有"明显的不在场证明"
└── 凶手：必须有"足够的嫌疑"和"足够的无辜证据"

步骤4：设计死亡顺序（3-5人）
├── 第1个死者：提供线索、减少嫌疑人
├── 第2-3个死者：维持恐慌、误导方向
├── 最后存活者：2-3人，包括凶手
└── 凶手策略：伪装受害者/伪装无辜/制造替罪羊

步骤5：设计核心诡计
├── 这个诡计必须只能在"封闭空间"中实现
├── 这个诡计利用了建筑的某个特点
└── 这个诡计被"隔离状态"掩护

步骤6：设计死亡预告（可选）
├── 童谣、预言、规律、倒计时……
├── 预告必须可被打破
└── 预告必须在最后揭示为"凶手的工具"

步骤7：写第一章
├── 介绍所有人物及其关系
├── 建立日常状态（让读者熟悉环境）
├── 引入"异常"（不一定是死亡，可以是预告）
└── 预埋至少3条将在后续章节回收的线索
```

#### 4.8 嫌疑人管理表的使用（15分钟）

**教师讲解**：
> "写暴风雪山庄时，你必须管理一个'嫌疑人集合'。"
> "每死一个人，这个集合就缩小。"
> "如果你管理不好，读者会提前猜到凶手，或者觉得被欺骗。"

**板书：嫌疑人管理表**
```
嫌疑人管理表（以《十角馆事件》为例）

初始名单：A、B、C、D、E、F、G、H（8人）
嫌疑指数：每人1-10分（10=最可疑）

第1人死亡后：
死者：A（不是凶手）
存活：B(6)、C(4)、D(7)、E(5)、F(3)、G(8)、H(2)
→ 重新评估每人的嫌疑指数
→ 注意：某人的嫌疑可能"上升"（因为死者死前与他有关）
→ 注意：某人的嫌疑可能"下降"（因为他有完美的不在场证明）

第2人死亡后：
死者：B（不是凶手）
存活：C(5)、D(8)、E(6)、F(4)、G(7)、H(3)
→ 继续更新

……

最后阶段：
存活：C、D、E
→ 三人中必须有凶手
→ 三人中必须有至少1个"看似无辜"的人
→ 凶手必须在"中间位置"（不是最可疑，也不是最无辜）
```

**关键原则**：
> "凶手在嫌疑人管理表中的位置应该遵循'钟形曲线'："
> "- 早期：凶手是'中等可疑'（不突出，也不被排除）"
> "- 中期：凶手的可疑度可能小幅上升或下降（波动）"
> "- 晚期：凶手的可疑度应该与另一个幸存者'几乎相同'"

### 第4学时（45分钟）：第一章仿写与期中准备

## 七、教师备查资料

### 7.1 《十角馆事件》详细拆解（教师参考）

**基本信息**：
- 首次发表：1987年
- 类型：新本格推理（长篇）
- 侦探：岛田洁（建筑系学生，后成为系列侦探）

**核心特点**：
- 新本格运动的开山之作
- 建筑诡计 + 暴风雪山庄 + 童谣预告
- 对阿加莎·克里斯蒂《无人生还》的致敬与超越

**与前6课技法的整合**：
- 结构：三段式的扩展（多章节对应多死亡）
- 密室：可能涉及建筑结构制造的"伪密室"
- 不在场证明：利用封闭空间的特殊性
- 逻辑链：岛田洁的推理过程
- 叙述：有限第三人称，信息控制
- 反转：凶手身份的揭示

### 7.2 新本格运动背景（教师参考）

**历史背景**：
- 1980年代，日本推理小说被社会派主导二十多年
- 年轻作家（岛田庄司、绫辻行人、我孙子武丸等）主张回归本格
- 1987年，岛田庄司发表《本格推理宣言》
- 同年，绫辻行人发表《十角馆事件》，标志新本格诞生

**核心主张**：
1. 推理小说应以"诡计"和"逻辑"为核心
2. 诡计可以更大胆、更华丽、更突破常规
3. 不排斥变格元素（恐怖、猎奇），但解答必须逻辑自洽
4. 建筑、民俗、专业知识可以作为诡计的外衣

### 7.3 常见学生问题与应对

| 学生问题 | 教师应对 |
|---------|---------|
| "我想不出特殊的建筑，能写暴风雪山庄吗？" | 回应：建筑不需要特殊。普通公寓、普通列车都可以。关键是"隔离"和"有限嫌疑人"。 |
| "我的人物太多了，记不住。" | 回应：减少人物。新手建议从6人开始（死3人，最后3人）。人物太多会分散读者的注意力。 |
| "凶手在'中间位置'死亡？这是什么意思？" | 回应：凶手可以"假装"死亡，或者制造"自己差点死了"的假象。这样凶手既在嫌疑人名单中，又不会被怀疑（因为"死者不会杀人"）。 |
| "期中作品必须写暴风雪山庄吗？" | 回应：不必须。期中作品可以是任何类型的本格推理（密室、不在场证明、逻辑推演等）。但暴风雪山庄是最容易展示综合技法的形式。 |

### 7.4 课堂时间备用方案

如果学生阅读速度快，第3-4学时可以增加：
- **"建筑诡计设计"竞赛**：给定一个普通建筑（学校、医院、办公楼），让学生设计一个"建筑诡计"
- **"死亡顺序投票"**：学生互相投票"谁应该第一个死""谁应该最后活"，讨论不同选择的叙事效果
