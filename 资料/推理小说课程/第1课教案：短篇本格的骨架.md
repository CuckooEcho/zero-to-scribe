# 第1课完整教案：短篇本格的骨架

> **精读作品**：江户川乱步《D坂杀人事件》（1925）
> **所属流派**：本格推理（日本侦探小说的原点）
> **课时**：4学时（每学时45分钟，共180分钟）
> **学生水平**：零基础入门

---

## 一、课程目标

### 知识目标
1. 理解短篇推理小说的基本结构（三段式：谜面→调查→解答）
2. 掌握"侦探作为读者代理人"的功能设计
3. 理解线索布置的"密度原则"与"回收原则"

### 能力目标
1. 能独立拆解一部短篇推理小说的结构，标注每部分的功能
2. 能按 1:2:1 比例写出结构完整的微型推理短篇（1500字）
3. 能识别"真线索"与"闲笔"的区别

### 情感目标
1. 建立"推理小说不是天才的专利，而是结构的艺术"的认知
2. 破除"必须想出奇妙的诡计才能写推理小说"的迷思

---

### 教师准备
1. 准备《D坂杀人事件》全文（中译本约8000字，学生课前已读）
2. 打印"课前阅读指引"发放给学生
3. 准备课堂讨论的PPT（或黑板板书要点）
4. 准备"模仿练习"的评分标准

### 学生课前任务（课前一周布置）

#### 阅读任务
- **必读**：《D坂杀人事件》全文
- **选读**：《莫格街凶杀案》（爱伦·坡，第一篇侦探小说，对比阅读）

#### 课前思考问题（学生需书面回答，课前交）

> **课前作业**：读完《D坂杀人事件》后，不看原文，凭记忆回答以下问题。目的是训练你的"读者记忆"——即读者在阅读时会注意到什么、记住什么。

1. 死者是谁？她是怎么死的？（测试你对"谜面"的记忆）
2. 侦探是谁？他在故事的第几页/第几段登场？（原文第27行首次被提及名字，第79行正式登场；测试你对"侦探登场"的感知）
3. 故事中出现了哪些"线索"？列出你能记住的所有细节。（提示：关注第39-55行"无窗"的异常、第61-74行伤痕传闻、第383-399行目击证词；测试你对"线索密度"的感知）
4. 凶手是谁？侦探是如何推理出来的？（解答集中在第477-731行，推理（下）全文；测试你对"解答"的记忆清晰度）
5. 用一个词形容读完这个故事的感受。（测试你的"直觉反应"）

## 三、课前阅读指引（发给学生）

### 《D坂杀人事件》怎么读？

**不要把它当"故事"读，把它当"建筑图纸"读。**

推理小说的阅读方式与普通小说不同。普通小说追求"沉浸"，推理小说追求"对抗"——你在和作者对抗，看谁先到达真相。

#### 阅读方法：双线阅读法

**第一线：故事线（跟着情节走）**
- 谁在什么时候做了什么？
- 谁死了？谁来了？谁说了什么？

**第二线：推理线（跟着逻辑走）**
- 这个细节为什么被提到？它是线索还是闲笔？
- 侦探为什么问这个问题？他在验证什么假设？
- 如果我是侦探，我现在会怀疑谁？为什么？

#### 带着这些问题读

1. **"时间"问题**：故事从案发到结束，经过了多长时间？每个场景的时间长度是多少？时间感对推理有什么影响？
2. **"空间"问题**：故事发生在几个地点？每个地点的功能是什么？（案发现场、侦探的住所、其他相关地点）
3. **"信息"问题**：作者在前半部分告诉了你哪些信息？哪些信息你觉得"可疑"或"多余"？
4. **"人物"问题**：故事中有几个出场人物？每个人物的"功能"是什么？（有人提供线索，有人制造干扰，有人是嫌疑对象）

#### 读完之后做一件事

合上书，拿出一张纸，尝试**画出这个故事的"结构图"**：

```
时间轴：─────────────────────────────────→
        案发      侦探登场      调查      解答
        ↑          ↑           ↑        ↑
        谜面建立   视角转换     线索收集   真相揭露
```

不用画得很精确，重点是让你"看见"这个故事的骨架。

## 四、课堂流程（4学时，180分钟）

---

### 第1学时（45分钟）：导入与谜面建立

#### 4.1 课程导入（10分钟）

**教师开场**：
> "在开始之前，我想问大家一个问题：你们为什么想写推理小说？"
>
> （等待学生回答，常见答案：喜欢解谜、想制造惊喜、喜欢某个作家……）
>
> "这些都是很好的理由。但我想告诉你们一个秘密：**世界上最好的推理小说作家，首先都是最好的推理小说读者。** 今天开始，我们不再只是'读'推理小说，我们要'拆'推理小说——像拆一台钟表一样，看清每一个齿轮是怎么咬合的。"
>
> "我们的第一台'钟表'，是日本推理小说的原点——江户川乱步的《D坂杀人事件》。"

**板书**：
```
第1课：短篇本格的骨架
作者：江户川乱步（1894-1965）
作品：《D坂杀人事件》（1925）
地位：日本侦探小说的开山之作
```

#### 4.2 作者与时代背景（10分钟）

**江户川乱步其人**：
- 本名平井太郎，"江户川乱步"的笔名来自埃德加·爱伦·坡（Edgar Allan Poe）的日文谐音
- 从小体弱，热爱阅读，尤其喜欢爱伦·坡、柯南·道尔
- 1923年发表《两分铜币》，正式出道
- 1925年发表《D坂杀人事件》，创造了日本第一个名侦探——明智小五郎

**时代背景**：
- 1925年的日本：大正末期，西学东渐，城市文化兴起
- 推理小说在日本是"舶来品"，乱步的任务是把欧美的侦探小说"翻译"成日本语境
- 旧书店、咖啡馆、和服、人力车——《D坂杀人事件》的"和风"场景，让日本读者感到亲切

**关键对比**：
| 欧美侦探小说 | 日本侦探小说（乱步开创） |
|-------------|------------------------|
| 福尔摩斯：独居、抽雪茄、化学实验 | 明智小五郎：住廉价公寓、无业、爱读书 |
| 伦敦：雾、马车、绅士 | 东京：旧书店、小巷、学生和商人 |
| 警察=无能 | 警察=几乎不出现 |

> **教学要点**：乱步的伟大之处不是发明了侦探小说，而是**把侦探小说种进了日本的土壤里**。他证明：侦探不需要是天才，他可以是一个像你像我一样的普通人。

#### 4.3 谜面建立：故事前1/4精读（15分钟）

**教师引导**：
> "现在请大家打开书，翻到开头。我们不急着往下读，我们只读前1/4——也就是'谜面建立'的部分（原文第7-155行，事实（上）从叙述者介绍到发现尸体）。"
>
> "读的时候，请用笔标出：作者用了多少字来建立'这里发生了谋杀'这个事实？"

**学生默读前1/4（或教师朗读关键段落）**

**讨论问题**：
1. 故事的第一句话是什么（第7行："那是发生在九月上旬某个闷热夜晚的事情"）？它起到了什么作用？
2. 死者是在第几段出现的（第155行："视线所及之处是一具女尸，横躺在房间角落"）？出场方式是什么？（直接出场？被提及？）
3. 作者用了哪些描写来让读者感到"这里发生了不寻常的事"？（提示：对比第39-55行"无窗"关上的异常、第61-74行老板娘伤痕传闻、第125-155进入现场发现尸体的过程）

**板书：谜面建立的要素**
```
谜面建立 = 异常现象 + 现场状态 + 初步疑问

《D坂杀人事件》的谜面：
- 异常：旧书店老板娘被杀（第155行发现尸体）
- 现场：门窗状态（第173-183行房间格局描述）、尸体状态（第185-193行）、"无窗"设计（第39-51行）
- 疑问：凶手如何进出？谁有动机？
```

#### 4.4 课间小结与过渡（10分钟）

**教师总结**：
> "前1/4的任务只有一个：让读者产生'想知道答案'的欲望。乱步用不到2000字完成了这个任务。他的方法是：快速建立一个'不可能的现场'，然后立刻引入侦探。"
>
> "下一学时，我们要看侦探是如何登场的——这是推理小说的关键技术。"

### 第2学时（45分钟）：侦探登场与调查推进

#### 4.5 侦探的登场方式（15分钟）

**教师引导**：
> "请大家回忆：明智小五郎是在故事的哪个位置登场的？（原文第27行首次被提及名字，第79行正式出现在咖啡厅）是在案发前、案发时、还是案发后？"
>
> （学生回答：案发后，警察已经调查之后）

**板书：侦探登场的时机**
```
侦探登场的三种时机：

1. 案发前登场（少见）
   → 功能：建立侦探的日常生活，让读者熟悉他
   → 案例：阿加莎《斯泰尔斯庄园奇案》（波洛在案发前已住入庄园）

2. 案发时登场（较常见）
   → 功能：侦探作为目击者，有第一手信息
   → 案例：柯南·道尔《血字的研究》（华生目击现场）

3. 案发后登场（最常见，本案属于此类）
   → 功能：侦探作为"外部智力"，用新鲜视角审视已有信息
   → 优势：可以让侦探和读者处于同一信息起点（最公平）
```

**《D坂杀人事件》中明智小五郎的登场分析**（原文第27行首次被提及，第79-84行正式登场）：
- 登场方式：通过"我"（叙述者）的介绍间接登场（第27行："最近我在白梅轩结识了一个奇特的男人，名叫明智小五郎"）
- 身份：无业青年，住廉价公寓，爱读书（叙述者第11-17行自述，可与明智形成镜像对照；明智的身份细节散见于第533-563行推理（下）中的补充介绍）
- 与传统侦探的区别：不是警察，不是职业侦探，而是"爱好者"（第533-547行："他是没有固定职业的游民"，"我的研究对象是人类"）
- 功能：代表"普通人的好奇心"，让读者产生亲近感

**讨论问题**：
1. 如果明智小五郎是一个像福尔摩斯那样的"天才"，故事会有什么不同？
2. 为什么乱步要让侦探"看起来不像侦探"？

#### 4.6 调查推进：线索的收集与排除（20分钟）

**教师引导**：
> "现在请大家翻到故事的中间部分——调查阶段。这个阶段占据了故事的约50%（原文第156-473行，事实（上）后半部分）。"
>
> "我想请大家做一件事：列出故事中出现的所有'线索'，无论大小。"

**学生分组活动（5分钟）**：
- 每组列出尽可能多的线索
- 然后标注：哪些线索最终被解答篇回收了？哪些没有？

**板书：线索清单**
```
《D坂杀人事件》主要线索（对应原文位置）：

1. 物理线索
   - 房间门窗状态（第173-183行：房间格局、拉门、檐廊、木板墙）
   - 尸体状态（第185-193行：位置、衣着、颈部指痕）
   - "无窗"设计（第39-51行：纸门结构、纵向双重格子）

2. 证言线索
   - 两名学生目击证词（第383-399行：一黑一白的矛盾证言）
   - 冰淇淋小贩证词（第329-342行：巷内无人进出）
   - 钟表行老板证词（第245-259行：老板去夜市摆摊）

3. 行为线索
   - 指纹异常（第305-313行：开关上只有明智的指纹）
   - 老板娘身上的伤痕（第61-74行传闻，第427-431行老板承认）
   - 荞麦店老板娘也有类似伤痕（第67行首次提及）
```

**教学要点：线索的"三问法"**

教师向学生介绍判断线索重要性的方法：

> 当你看到一个细节时，问自己三个问题（我们以第61-74行"伤痕传闻"为例）：
> 1. **"这个细节如果不存在，故事还能成立吗？"** → 如果不能，它是核心线索
> 2. **"这个细节在当前段落中的作用是什么？"** → 是推动情节？是塑造氛围？是误导？
> 3. **"作者为什么要在这里提到这个细节？"** → 是为了让读者记住？还是为了让读者忽略？

**案例应用**：
- 分析《D坂杀人事件》中的1-2条具体线索，用"三问法"拆解（推荐：第61-74行伤痕传闻、第383-399目击证词）

#### 4.7 调查阶段的"节奏控制"（10分钟）

**教师讲解**：
> "调查阶段最大的写作风险是'无聊'。如果侦探只是按部就班地问话、收集线索，读者会失去兴趣。"
>
> "乱步的解决方法是：让调查阶段本身成为'第二重谜面'——注意第349-373行，凶手如何离开？作者不断抛出新的不可能性。"

**板书：调查阶段的节奏公式**
```
调查阶段 = 线索发现 + 假说提出 + 假说否定 + 新线索发现（循环）

每一轮循环的长度：短篇约500-800字
循环的次数：短篇2-3轮，长篇5-10轮

《D坂杀人事件》的调查阶段（原文第156-473行）：
第1轮：现场勘察与法医验尸（第217-236行）→ 提出假说A（熟人作案？）
第2轮：询问邻居与目击证词（第245-342行、第383-399行）→ 发现矛盾（黑白衣服、指纹异常）
第3轮：小林刑警调查无果（第363-445行）→ 案件走入死胡同
```

### 第3学时（45分钟）：解答篇的结构与公平性原则

#### 4.8 解答篇精读（15分钟）

**教师引导**：
> "请大家翻到故事的解答部分（原文第477-731行，推理（下）全文）。这是推理小说的' payoff '——读者读完全部的回报。"
>
> "解答篇的质量，决定了读者会不会推荐这本书给朋友。"

**学生默读解答篇**

**讨论问题**：
1. 侦探是从哪条线索开始推理的？（突破口：第709行"旧书店老板娘身上的多处伤痕"，以及第709-710行"荞麦面店的老板娘身上也有多处类似的伤痕"）
2. 侦探的推理过程用了几步？每一步的依据是什么？（提示：第627-695行反驳"我"的错误推理；第703-715行正面推理真相）
3. 解答有没有让你感到"不公平"？（即：有没有某条关键线索是你没注意到的？——可对照第61-74行的伤痕传闻，是否在阅读时被当作了"闲笔"而忽略？）

#### 4.9 公平性原则详解（20分钟）

**板书：公平性原则**
```
公平性原则 = 作者与读者的"信息契约"

契约内容：
1. 作者向读者展示的所有信息，侦探也可以获得
2. 侦探使用的推理依据，必须在文中以某种形式出现过
3. 作者不能引入"未事先说明的规则"（例如：突然说"凶手有超能力"）

违反公平性的后果：
- 读者感到被欺骗（"这不可能猜到！"）
- 阅读乐趣丧失（"反正作者说什么就是什么"）
- 作品被归类为"悬疑"而非"推理"
```

**公平性的"灰色地带"**：

| 行为 | 是否违反公平性 | 说明 |
|------|--------------|------|
| 侦探注意到一条读者没注意的线索 | 不违反 | 信息已向读者展示，只是读者没注意到 |
| 侦探获得一条读者没见过的线索 | 违反 | 信息不对等 |
| 作者用误导性叙述让读者误解线索 | 不违反（但争议） | 信息已展示，只是被"包装"了 |
| 作者在最后引入全新的人物关系 | 严重违反 | 读者没有推理的基础 |

**《D坂杀人事件》的公平性检验**（以下线索均可在原文中找到对应位置）：
- 关键线索是否在解答前出现？→ 是（第61-74行伤痕传闻、第67行荞麦店老板娘也有伤）
- 线索是否被"包装"成不起眼的样子？→ 是（传闻被夹杂在日常对话中，第61-74行；这是技巧，不违反公平性）
- 解答是否依赖读者不知道的"额外信息"？→ 否（第709-715行真相所依赖的所有信息均已在事实（上）中出现）

**结论**：《D坂杀人事件》是一部严格遵守公平性的本格推理。

#### 4.10 解答篇的写作模板（10分钟）

**板书：解答篇的标准结构**
```
解答篇结构（适用于短篇）：

1. 重申谜面（10%）
   → "让我们回顾一下：我们面对的是什么样的谜题？"
   → 功能：确保读者记得所有需要解释的点

2. 排除不可能（20%）
   → "首先，X是不可能的，因为……"
   → "其次，Y也是不可能的，因为……"
   → 功能：缩小可能性空间，制造"唯一解"的必然感

3. 指出关键线索（20%）
   → "然而，我们忽略了一条重要的线索……"
   → 功能：这是读者"啊！"的时刻

4. 逻辑推导（40%）
   → "这条线索意味着什么？它意味着……"
   → "而如果我们接受这个前提，那么……"
   → 功能：展示推理链条，让读者跟随每一步

5. 真相揭露（10%）
   → "因此，凶手只能是……"
   → 功能：闭合逻辑链条，提供满足感
```

### 第4学时（45分钟）：技法提炼与模仿练习

#### 4.11 本课技法总结（10分钟）

**板书：从《D坂杀人事件》学到的3个核心技法**

```
技法1：短篇的1:2:1黄金比例
┌─────────────────────────────────────┐
│  谜面（25%）│ 调查（50%）│ 解答（25%）│
└─────────────────────────────────────┘
→ 短篇推理小说的骨架，初学者必须严格遵守

技法2：侦探的"读者代理人"设计
┌─────────────────────────────────────┐
│ 侦探的任务不是"秀智商"，而是"带路"   │
│                                     │
│ 他/她的困惑 = 读者的困惑            │
│ 他/她的发现 = 读者的发现            │
│ 他/她的推理 = 读者可以跟上的推理    │
└─────────────────────────────────────┘

技法3：线索的"高密度+全回收"原则
┌─────────────────────────────────────┐
│ 短篇中，每出现一条信息，都要问自己： │
│ "这条信息在解答中有没有用？"         │
│                                     │
│ 示例：第61-74行伤痕传闻             │
│ → 初读以为是塑造氛围的"闲笔"        │
│ → 实则是第709行推理真相的核心线索   │
│ → 乱步的技巧：把最重要的线索藏在    │
│    最不起眼的地方                   │
│                                     │
│ 如果有用 → 它是线索 → 要让它显眼   │
│ 如果没用 → 它是闲笔 → 短篇中尽量   │
│            不要出现                 │
└─────────────────────────────────────┘
```

#### 4.12 模仿练习：课堂实战（20分钟）

**练习题目**：短篇骨架仿写

> **题目**：用1500字写一个微型推理短篇，严格遵循 1:2:1 的结构比例。
>
> **具体要求**：
> 1. 开头375字：建立谜面。一个人死在房间里，有1-2个异常现象。不要写动机，不要写凶手，只写"发生了什么"。
> 2. 中段750字：一个侦探（或调查者）登场。他/她收集3条线索，提出2个假说，逐一否定。侦探可以是任何人（学生、邻居、送外卖的）。
> 3. 结尾375字：解答揭晓。回收所有线索。真相可以简单（例如：门其实没锁，只是被卡住了），不需要复杂的诡计。
>
> **写作时间**：15分钟
> **字数要求**：1200-1800字

**教师巡视指导**（15分钟）：
- 提醒学生注意时间分配
- 对卡壳的学生给予提示："你的谜面是什么？先写出来，不要想太复杂。"
- 对写得快的学生："检查一下，你的3条线索在解答中都有回收吗？"

#### 4.13 互评与点评（15分钟）

**互评规则**：
1. 学生两两交换作品（2分钟）
2. 互评标准（5分钟阅读+评分）：

| 评分项 | 分值 | 评价标准 |
|--------|------|---------|
| 结构完整性 | 30分 | 是否有清晰的三段式结构？比例是否大致合理？ |
| 线索回收 | 30分 | 出现的线索是否在解答中被回收？ |
| 逻辑自洽 | 20分 | 解答是否能解释谜面？有无自相矛盾？ |
| 可读性 | 20分 | 语言是否流畅？是否有明显的"写作腔"？ |
| **总分** | **100分** | |

3. 学生互评后，选择1-2篇作品进行全班点评（教师主导，8分钟）

**点评要点**：
- 先指出优点（"这篇的谜面建立很清晰"）
- 再指出可改进之处（"如果线索2在调查阶段更突出一些，解答会更有力"）
- 不涉及文学性评价（如"文笔好不好"），只关注结构和技术

### 作业1：结构修改（必做）

> 根据课堂互评的反馈，修改你的微型推理短篇。重点修改以下一个方面：
> 1. 如果结构比例失衡（例如谜面太长或解答太短），调整段落长度
> 2. 如果有线索未被回收，要么在解答中回收它，要么删除它
> 3. 如果解答无法解释谜面，重新设计解答

### 作业3：线索敏感度训练（日常练习）

> 本周任选一天，记录你遇到的3件"小事"，并问自己：如果这是推理小说的线索，它可能指向什么？

> - 电梯里有人按了错误的楼层 → 可能指向：这个人不熟悉这栋楼，或者他在制造不在场证明
> - 咖啡店的常客今天没来 → 可能指向：他遇到了什么事，或者他平时来咖啡店是为了观察某人
>
> 不需要合理，只需要训练"把日常变成线索"的敏感度。

## 七、教师备查资料

### 7.1 《D坂杀人事件》详细拆解（教师参考）

**基本信息**：
- 首次发表：1925年，《新青年》杂志
- 中译本字数：约8000字
- 类型：短篇本格推理
- 侦探：明智小五郎（首次登场）

**结构拆解（精确版，对应MD行号）**：

| 部分 | 原文位置 | 功能 | 关键事件 |
|------|---------|------|---------|
| 开头（背景介绍） | 第7-26行 | 建立叙述者"我"的视角 | D坂环境、白梅轩咖啡厅、旧书店 |
| 人物铺垫 | 第27-36行 | 引入核心人物 | 明智小五郎首次被提及、老板娘传闻 |
| 异常发生 | 第37-76行 | 制造悬念 | "无窗"关上、叙述者持续观察 |
| 侦探登场 | 第77-124行 | 侦探正式出场 | 明智来到咖啡厅，两人对话 |
| 进入现场 | 第125-155行 | 谜面正式建立 | 发现尸体、初步判断 |
| 调查阶段 | 第156-473行 | 收集线索，提出假说 | 警方验尸、小林刑警登场、证人询问 |
| 解答阶段 | 第477-731行 | 逻辑推导，真相揭露 | "我"的错误推理、明智反驳、真相揭露 |
| 结尾 | 第721-731行 | 收尾，情感余韵 | 报纸报道凶手自首、发表信息 |

**核心诡计**（防剧透，课堂上根据学生阅读情况决定是否完全揭示）：
- 类型：心理密室+认知误导（原文第631行指纹真相、第639-687行证人记忆实验、第709-715行伤痕与心理诊断）
- 关键点：现场的"异常"不是机械机关造成的，而是人的认知盲区造成的（第695行："人类的观察力与记忆力其实相当不可靠"）
- 公平性：所有关键线索在调查阶段均已出现（第61-74行伤痕传闻、第383-399目击证词、第305-313行指纹）

### 7.2 常见学生问题与应对

| 学生问题 | 教师应对 |
|---------|---------|
| "我想不出复杂的诡计怎么办？" | 强调：第1课不追求诡计复杂，只追求结构完整。乱步的诡计其实也很简单。 |
| "我的解答太明显了，读者一看就知道凶手是谁。" | 引导：短篇的谜底不需要"难到猜不出"，只需要"逻辑自洽"。明显的谜底也可以通过好的结构写得好看。 |
| "我写的是社会派，不是本格，是不是不符合要求？" | 回应：先学好本格的结构，再写社会派。社会派也需要完整的逻辑链条。 |
| "我觉得《D坂杀人事件》不好看/过时了。" | 回应：我们从这部作品中学习的是"技术"，不是"审美"。技术不会过时。 |

### 7.3 课堂时间备用方案

如果学生阅读速度快，第3-4学时可以增加：
- **"改写练习"**：给定《D坂杀人事件》的谜面，让学生用不同的侦探形象重新写调查阶段（例如：把明智小五郎换成一个女大学生、一个退休老人、一个送外卖的小哥）
- **"结构变形"**：让学生把《D坂杀人事件》改写成"倒叙结构"（从解答开始，回溯调查过程），体验不同结构的效果
