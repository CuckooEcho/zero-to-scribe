# app · 故事结构板

写作辅助软件原型。当前版本：**泳道节拍板（Swimlane Beat Board）**，以《解忧杂货店》为案例数据。

## 运行

```bash
cd app
npm install
npm run dev
```

## 核心设计

数据模型：`beat（事件）× lane（故事线）× time（双重时间：叙述顺序 + 故事内时间）`

- **节拍板视图**：泳道 = 故事线，列 = 章节叙述顺序，卡片 = 节拍（类型/故事内年份/情绪值）
- **真实时间线视图**：同一批节拍按故事内年份重排，时空跳跃的结构立刻现形
- **弧光曲线视图**：每条故事线的情绪值折线，检查节奏塌陷
- 点击泳道名 = 单线裸读（character pass）；点击卡片 = 详情面板；⚡ = 伏笔配对高亮

## 数据

`src/data/beats.ts` — 节拍、泳道、章节的全部数据，字段即卡片库字段的延伸。

## 规划方向

- 卡片库的浏览、检索与组合（对接仓库 `卡片库/`）
- 场景写作流水线的引导式填卡（对接 `模板/场景写作流水线.md`）
- 自定义作品数据的录入与导入导出
